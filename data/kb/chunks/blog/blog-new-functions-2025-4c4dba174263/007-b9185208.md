25\.8, [`timeSeriesRange`](https://clickhouse.com/docs/sql-reference/functions/time-series-functions#timeSeriesRange) allows us to generate a range of timestamps. It’s like the range function, but for DateTimes. It returns an array of values, but we can use the `arrayJoin` function to explode the array into individual rows:

```
1SELECT arrayJoin(
2  timeSeriesRange(
3    '2025-06-01 00:00:00'::DateTime, 
4    '2025-06-01 00:01:00'::DateTime, 
5    10
6)) AS ts;
```

We could then work out how long it’s been since each of those times:

```
1WITH toDateTime('2025-12-17 12:32:12') AS currentTime
2SELECT arrayJoin(
3  timeSeriesRange(
4    '2025-06-01 00:00:00'::DateTime, 
5    '2025-06-01 00:01:00'::DateTime, 
6    10
7)) AS ts,
8  formatReadableTimeDelta(now() - ts) AS timeAgo;
```
