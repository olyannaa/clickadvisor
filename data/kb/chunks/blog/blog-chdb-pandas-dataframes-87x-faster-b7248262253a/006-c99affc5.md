Function \# After several weeks of development, we now have `chdb.PyReader`. You only need to inherit this class and implement the read function to use Python to define the data returned by a ClickHouse Table Function. Like this:

```
1import chdb
2
3class MyReader(chdb.PyReader):
4    def __init__(self, data):
5        # some basic init
6
7    def read(self, col_names, count):
8        # return col_names*count block
```

And then, we can use our new reader like this:

```
1# Initialize reader with sample data
2reader = MyReader({
3    "a": [1, 2, 3, 4, 5, 6],
4    "b": ["tom", "jerry", "auxten", "tom", "jerry", "auxten"],
5})
6
7# Execute a query on the Python reader and display results
8chdb.query("SELECT b, sum(a) FROM Python('reader') GROUP BY b").show()
```

### SQL on API \#

With chdb.PyReader, you can define your own data return logic using Python. So I made a [demo for querying Google Calendar using SQL](https://github.com/auxten/SQL-On-Everything/tree/main/google-calendar). By running:

```
1python google_cal.py \
2  "SELECT summary, organizer_email, parseDateTimeBestEffortOrNull(start_dateTime) WHERE status = 'confirmed';"
```
Copy command
You can retrieve all your accepted meeting invitations:

![9_unnamed (4).png](/_next/image?url=%2Fuploads%2F9_unnamed_4_98dcb65087.png&w=2048&q=75)

Through the API provided by chDB, you can easily treat many APIs that return JSON arrays as a ClickHouse table to run SQL queries. You don’t need to store additional data or manually define table structures.

All the above features are available in [chDB v2\.0\.2](https://github.com/chdb-io/chdb/releases/tag/v2.0.2) and later versions, which you can install by running the following:

```
1pip install "chdb>=2.0.2"
```
