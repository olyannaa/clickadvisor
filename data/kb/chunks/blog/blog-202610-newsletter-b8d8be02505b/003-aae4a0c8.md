![](/_next/image?url=%2Fuploads%2Foct2026_nl_image6_9d8e41db12.png&w=2048&q=75)

Executable UDFs, which let you upload your own functions and call them from SQL, are now generally available on ClickHouse Cloud on AWS, GCP, and Azure.

Since the beta, they've added a native runtime for precompiled Rust, Go, C\+\+, and JavaScript binaries, outbound network access, and a `deterministic` flag that lets the query cache serve queries that call a UDF.

The blog post shows a Rust UDF that counts LLM tokens at insert time and a Python UDF that calls Claude to grade a sample of completions.

## Postgres Round\-up \#

![](/_next/image?url=%2Fuploads%2Foct2026_nl_image7_5ea62fbef0.jpg&w=2048&q=75)

The Postgres Round\-up is back for a second month. This time we've got recaps from Postgres Summit US, PGDay Lowlands, and Percona Live Amsterdam, as well as deep dives into memory safety and running Postgres on local NVMe storage.

- David Wheeler [looks back on Postgres Summit US 2026](https://clickhouse.com/blog/postgres-summit-us-2026?utm_source=clickhouse&utm_medium=email&utm_campaign=202610-newsletter&ref=newsletter) in New York, where he demoed four tools that connect Postgres and ClickHouse, including `pg_clickhouse` and `pg_stat_ch`.
- Gülçin Yıldırım Jelínek [shares notes from PGDay Lowlands and Percona Live Amsterdam](https://clickhouse.com/blog/postgres-week-in-the-netherlands-pgday-lowlands-percona-live-2026?utm_source=clickhouse&utm_medium=email&utm_campaign=202610-newsletter&ref=newsletter), where she spoke about `pg_clickhouse`, `pg_stat_ch` and PostgreSQL 19 monitoring.
- Philip Dubé [explains how ClickHouse's Postgres extensions safely combine C and C\+\+](https://clickhouse.com/blog/memory-safety-postgres-extensions-c-cpp?utm_source=clickhouse&utm_medium=email&utm_campaign=202610-newsletter&ref=newsletter), with each taking a different approach, from removing C\+\+ entirely to running it in a separate helper process.
- David Wheeler [walks through the latest `pg_clickhouse` and chdb extension releases](https://clickhouse.com/blog/pg_clickhouse-chdb?utm_source=clickhouse&utm_medium=email&utm_campaign=202610-newsletter&ref=newsletter), which add character\-encoding checks and improve support for nested data, JSON, and type mappings.
- Kevin Biju Kizhake Kanichery [tests how Postgres providers handle a query that exhausts memory](https://clickhouse.com/blog/can-your-postgres-survive-a-bad-query?utm_source=clickhouse&utm_medium=email&utm_campaign=202610-newsletter&ref=newsletter), and explains why ClickHouse Managed Postgres fails a query rather than letting the whole database go down.
- Kaushik Iska [argues that slow Postgres is often slow storage](https://clickhouse.com/blog/postgres-on-nvme?utm_source=clickhouse&utm_medium=email&utm_campaign=202610-newsletter&ref=newsletter), showing how local NVMe helps once the working set outgrows memory, and where analytics still needs ClickHouse.
