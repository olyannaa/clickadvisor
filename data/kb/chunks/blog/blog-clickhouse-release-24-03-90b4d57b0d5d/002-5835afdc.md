In version 24\.4 or 24\.5, we plan to promote the analyzer to production and remove the old query analysis implementation.

One thing that the old query runtime couldn’t handle very well was queries that used nested CTEs and joins. For example, the following query should return the number 1:

```
1WITH example AS (
2    SELECT '2021-01-01' AS date, 1 AS node, 1 AS user
3)
4SELECT extra_data 
5FROM (
6    SELECT join1.*
7    FROM example
8    LEFT JOIN (
9        SELECT '2021-01-01' AS date, 1 AS extra_data
10    ) AS join1
11    ON example.date = join1.date
12LEFT JOIN (
13    SELECT '2021-01-01' AS date
14) AS join2
15ON example.date = join2.date);
```
