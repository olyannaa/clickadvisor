We want to massage the data so that we can see the reviews line\-by\-line alongside product information. We can do this with the following query:

```
1SELECT
2    review.rating AS rating,
3    review.comment,
4    product.product_id AS id,
5    product.name AS name
6FROM `products.json`
7ARRAY JOIN products AS product
8ARRAY JOIN product.reviews AS review
9ORDER BY rating DESC
```
