In addition to using the Play UI, if you want to query the data directly, you can connect to the database using the read\-only `play` user using ClickHouse Client:

```
1./clickhouse client \
2  -h clickpy-clickhouse.clickhouse.com \
3  --user play --secure \
4  --database pypi
```
