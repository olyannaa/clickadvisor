Users can also use chDB for querying existing tabular structures such as Pandas data frames, allowing code to be simplified and accelerated with ClickHouse SQL. In the example below we populate a dataframe with some dummy date, before repeating the above query. Note the `__table__` syntax used in the query.

```
1import chdb.dataframe as cdf
2from datetime import datetime, timedelta
3import pandas as pd
4import random
5
6# Populate the DataFrame with random house sales data
7data = []
8start_date = datetime(2010, 1, 1)
9end_date = datetime(2023, 12, 31)
10for _ in range(10000):
11   date = start_date + timedelta(days=random.randint(0, (end_date - start_date).days))  # Random date
12   price = random.randint(100000, 1000000)  # Random price between 100000 and 1000000
13   data.append({'date': date, 'price': price})
14df = pd.DataFrame(data)
15
16
17
18tbl = cdf.Table(dataframe=df)
19df = tbl.query('SELECT toYear(date::Date32) AS year, round(avg(price)) AS price FROM __table__ GROUP BY year ORDER BY year')
20
21print(df)
```

Finally, users can also query and return data in any of the many formats supported by ClickHouse. Below we query a gzip CSV sample of the UK house price dataset, returning the result in Arrow.

```
1import chdb
2
3res = chdb.query(
4   f"SELECT town, district, count() AS c, round(avg(price)) AS price "
5   f"FROM s3('https://datasets-documentation.s3.eu-west-3.amazonaws.com/uk-house-prices/csv/house_prices.csv.gz') "
6   f"GROUP BY town, district HAVING c >= 100 ORDER BY price DESC LIMIT 10",
7   "ArrowTable")
8
9print(res)
```
