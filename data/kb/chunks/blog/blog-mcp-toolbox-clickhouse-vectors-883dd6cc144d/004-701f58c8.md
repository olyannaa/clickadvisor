Copy commandAn FYI before you write any YAML: **1\.9 prefers a flat config format**. Each resource is its own YAML document with `kind`, `name`, and `type` keys, separated by `---`. Older examples on the internet use a nested format (`sources:` → `my-clickhouse:` → …) where `kind` carries the type. That older shape still parses and runs fine in 1\.9 (I kept a nested config around and it executed happily) so nothing is broken if you have one. `toolbox migrate` converts it when you want the new shape, and all the examples below use it.
