\- and if you need to squeeze retrieval quality, this is the knob you'd reach for first and the one you can't currently turn. Embedding outside Toolbox is the only way to set it today. **The ingestion tool**

Here's the clever bit. On insert you need the same text twice \- once to store as `String`, once to embed into the vector column. Asking an LLM to repeat an identical string across two parameters is wasteful and error\-prone, so Toolbox has `valueFromParam`: a hidden parameter that mirrors another parameter's value. It never appears in the tool manifest \- the agent doesn't know it exists:

```
1kind: tool
2name: insert_doc
3type: clickhouse-sql
4source: my-clickhouse
5description: Indexes a new document and its vector embedding.
6statement: |
7  INSERT INTO vectors.documents (content, embedding) VALUES (?, ?)
8parameters:
9  - name: content
10    type: string
11    description: The text content to store.
12  - name: text_to_embed
13    type: string
14    description: Hidden copy of content, embedded as a vector.
15    valueFromParam: content
16    embeddedBy: gemini-embedder
```
Copy commandAsking the server for its tool manifest over MCP returns a single property for `insert_doc`:

```
1- execute_sql    | params: sql
2- insert_doc     | params: content
3- list_databases | params: none
4- list_tables    | params: database
5- search_docs    | params: query
```
Copy command**The search tool.**  

The agent supplies plain text; Toolbox embeds it and binds the vector to the `?`:

```
1kind: tool
2name: search_docs
3type: clickhouse-sql
4source: my-clickhouse
5description: Finds the most semantically similar documents to a query.
6statement: |
7  SELECT content, cosineDistance(embedding, ?) AS distance
8  FROM vectors.documents
9  ORDER BY distance ASC
10  LIMIT 5
11parameters:
12  - name: query
13    type: string
14    description: The natural-language search query.
15    embeddedBy: gemini-embedder
```
Copy commandOptionally, group them into a toolset so clients can load just these two:

```
1kind: toolset
2name: semantic_search
3tools:
4  - insert_doc
5  - search_docs
```
