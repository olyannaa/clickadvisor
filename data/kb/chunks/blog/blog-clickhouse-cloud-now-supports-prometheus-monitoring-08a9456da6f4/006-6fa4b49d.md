Prometheus scraping job for the ClickHouse Cloud. You'll need `<ORG_ID>`, `<INSTANCE_ID>`, `<KEY_ID>` and `<KEY_SECRET>` from the steps above. Note the `honor_labels` configuration parameter. It needs to be set in `true` for the instance label to be properly populated.

```
1global:
2  scrape_interval: 15s
3scrape_configs:
4  - job_name: "prometheus"
5    static_configs:
6    - targets: ["localhost:9090"]
7  - job_name: "clickhouse"
8    static_configs:
9      - targets: ["api.clickhouse.cloud"]
10    scheme: https
11    metrics_path: "/v1/organizations/<ORG_ID>/services/<INSTANCE_ID>/prometheus"
12    basic_auth:
13      username: <KEY_ID>
14      password: <KEY_SECRET>
15    honor_labels: true
```

## Datadog example \#

You can use the Datadog Agent and [OpenMetrics integration to collect metrics](https://docs.datadoghq.com/integrations/guide/prometheus-host-collection/) from the ClickHouse Cloud endpoint. Below is a simple example configuration for this agent.

```
1init_config:
2
3instances:
4   - openmetrics_endpoint: 'https://api.control-plane.clickhouse.com/v1/organizations/97a33bdb-4db3-4067-b14f-ce40f621aae1/services/f7fefb6e-41a5-48fa-9f5f-deaaa442d5d8/prometheus'
5     namespace: 'clickhouse'
6     metrics:
7         - '^ClickHouse_.*'
8     username: username
9     password: password
```
