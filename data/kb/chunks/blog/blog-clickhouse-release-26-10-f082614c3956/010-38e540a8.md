```
1CREATE TABLE uk_price_paid_by_date
2ENGINE = MergeTree
3ORDER BY date
```

This copies all 30m sales and merges the new table into a single part. We’ll run the query on ClickHouse 26\.10 so we can see what the output looks like:

```
1SELECT
2    date,
3    count() AS sales,
4    round(avg(price)) AS average_price
5FROM uk_price_paid_by_date
6GROUP BY date
7ORDER BY date DESC
8LIMIT 10
9SETTINGS
10    enable_group_by_top_k_dynamic_filtering = 0,
11    use_query_condition_cache = 0,
12    use_query_cache = 0;
```
