Infrastructure as Code (IaC), a new `pubsub` source type is available in [the ClickPipes OpenAPI specification](https://clickhouse.com/docs/cloud/manage/api/swagger#tag/ClickPipes), as well as the ClickHouse Terraform Provider ([3\.16\.0\+](https://github.com/ClickHouse/terraform-provider-clickhouse/releases/tag/v3.16.0)). Here's an example of how you'd configure a GCP Pub/Sub ClickPipe resource in Terraform:

```
1resource "clickhouse_clickpipe" "pubsub" {
2  service_id = var.service_id
3  name       = var.pipe_name
4
5  source = {
6    pubsub = {
7      format         = "JSONEachRow"
8      project_id     = var.gcp_project_id
9      topic          = var.pubsub_topic
10      authentication = "SERVICE_ACCOUNT"
11      seek_type      = "latest"
12
13      service_account_key = {
14        service_account_file = var.gcp_service_account_b64
15      }
16    }
17  }
18
19  destination = {
20    table         = var.table
21    managed_table = true
22
23    table_definition = {
24      engine = {
25        type = "MergeTree"
26      }
27    }
28
29    columns = [
30      {
31        name = "my_field1"
32        type = "String"
33      },
34      {
35        name = "my_field2"
36        type = "UInt64"
37      },
38    ]
39  }
40
41  field_mappings = [
42    {
43      source_field      = "my_field"
44      destination_field = "my_field1"
45    }
46  ]
47}
48
49output "clickpipe_id" {
50  value = clickhouse_clickpipe.pubsub.id
51}
```

## How to sign up for Private Preview? \#

The GCP Pub/Sub connector is available upon request, and **free** to use during Private Preview. Fill out [this form](https://clickhouse.com/cloud/clickpipes#pubsub-private-preview) to join the waitlist, or reach out to your ClickHouse Cloud account manager. To get started with step\-by\-step instructions, check out the [documentation for GCP Pub/Sub ClickPipes](https://clickhouse.com/docs/integrations/clickpipes/pubsub).
