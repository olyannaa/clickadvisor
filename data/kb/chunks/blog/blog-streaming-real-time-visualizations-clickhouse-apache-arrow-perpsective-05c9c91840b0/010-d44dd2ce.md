we need the [Arrow js lib](https://arrow.apache.org/docs/js/). While this makes consuming Arrow files trivial, to support streaming we need a bit more JS. Our final function which streams the entire dataset a batch at a time is shown below.

```

2   const view = await table.view({ // Create a view with aggregation to get the maximum datetime value
3       columns: ["last_update"], // Column you're interested in
4       aggregates: { last_update: "max" } // Aggregate by the maximum of datetime
5   });
6   const response = await fetch(clickhouse_url, {
7       method: 'POST',
8       body: `SELECT concat(base, '.', quote) AS base_quote, datetime AS last_update, bid::Float32 as bid,  ask::Float32 as ask, ask - bid AS spread
9              FROM forex WHERE datetime > ,[object Object],::DateTime64(3) ORDER BY datetime ASC FORMAT ArrowStream SETTINGS output_format_arrow_compression_method='none'`,
10       headers: { 'Authorization': `Basic ,[object Object],` }
11   });
12   const reader = await RecordBatchReader.from(response);
13   await reader.open();
14   for await (const recordBatch of reader) {  // Continuously read from the stream
15       if (real_time) { // set to false if we want to stop the stream
16           await view.delete();
17           return;
18       }
19       const batchTable = new Table(recordBatch); // currently required, see https://github.com/finos/perspective/issues/1157
20       const ipcStream = tableToIPC(batchTable, 'stream');
21       const bytes = new Uint8Array(ipcStream);
22       table.update(bytes);
23       const result = await view.to_columns();
24       const maxDateTime = result["last_update"][0];
25       document.getElementById("last_updated").textContent = `Last updated: ,[object Object],`;
26       total_size += (bytes.length);
27       document.getElementById("total_download").textContent = `Total Downloaded: ,[object Object],`;
28   }
29}
```

This code could be more efficient than it is \- mainly as Perspective currently [requires an array of bytes](https://github.com/finos/perspective/issues/1157) for the update call. This forces us to convert our batch to a table and stream this to an array. We also use a Perspective view, conceptually similar to a materialized view in ClickHouse \- executing an aggregation on the table data as it's loaded. In this case, we use the view to simply compute the maximum streamed date, which we show in the final UI.

With a little additional code to switch between the earlier "real\-time" polling mode and this "streaming mode," we have our final app. Switching to streaming mode shows the performance of Perspective:
