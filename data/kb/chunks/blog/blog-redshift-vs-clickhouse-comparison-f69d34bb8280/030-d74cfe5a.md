original BigQuery query, documented as part of [Awesome BigQuery views](https://github.com/blockchain-etl/awesome-bigquery-views/blob/master/ethereum/ether-supply-by-day.sql) and discussed [here](https://medium.com/google-cloud/how-to-query-ether-supply-in-bigquery-90f8ae795a8), executes in 428ms in Redshift. The ClickHouse query runs in 87ms. Using [projections](https://clickhouse.com/docs/en/engines/table-engines/mergetree-family/mergetree/#projections), this query can be further optimized to run in under 10ms secs.

```
1WITH ether_emitted_by_date AS (
2  SELECT
3    date(block_timestamp) AS date,
4    SUM(value) AS value
5  FROM
6    traces
7  WHERE
8    trace_type IN ('genesis', 'reward')
9  GROUP BY
10    DATE(block_timestamp)
11)
12SELECT
13  date,
14  SUM(value) OVER (
15    ORDER BY
16      date ASC ROWS BETWEEN UNBOUNDED PRECEDING
17      AND CURRENT ROW
18  ) / POWER(10, 18) AS supply
19FROM
20  ether_emitted_by_date
21LIMIT
22  10;
```
