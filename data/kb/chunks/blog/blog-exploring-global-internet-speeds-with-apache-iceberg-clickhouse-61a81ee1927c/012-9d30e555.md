Finally, as we’ll see below, it might also be helpful to be able to retrieve the polygon for a country efficiently based on its name. This can be achieved with a simple dictionary using the same `countries` table.

```
1CREATE DICTIONARY default.country_names
2(
3	`coordinates` MultiPolygon,
4	`name` String
5)
6PRIMARY KEY name
7SOURCE(CLICKHOUSE(TABLE 'countries'))
8LIFETIME(MIN 0 MAX 0)
9LAYOUT(COMPLEX_KEY_HASHED())
10
11SELECT dictGet(country_names, 'coordinates', 'Yemen') AS coords
```
