Fortunately, this is [relatively simple to compute](https://en.wikipedia.org/wiki/Centroid#Of_a_polygon) as our polygons are non\-self\-intersecting and closed. For the curious reader, some sample Python code ([credit](https://stackoverflow.com/questions/75699024/finding-the-centroid-of-a-polygon-in-python)) is shown below.

```
1def centroid(vertices):
2	x, y = 0, 0
3	n = len(vertices)
4	signed_area = 0
5       # computes the signed area and y and x accumulators - signed_area UDF function
6	for i in range(len(vertices)):
7    	  x0, y0 = vertices[i]
8    	  x1, y1 = vertices[(i + 1) % n]
9    	  # shoelace formula - maps to area function below
10    	  area = (x0 * y1) - (x1 * y0)
11    	  signed_area += area
12    	  x += (x0 + x1) * area
13    	  y += (y0 + y1) * area
14       # final step of centroid function
15	signed_area *= 0.5
16	x /= 6 * signed_area
17	y /= 6 * signed_area
18	return x, y
19

21print(x,y)
```

Converting this to a SQL UDF we can use at query time is simplest if we decompose the problem into several functions.

```
1CREATE FUNCTION area AS (v1,v2) -> ((v1.1 * v2.2) - (v2.1 * v1.2))
2
3CREATE FUNCTION signed_area AS polygon ->
4   (
5       arrayFold((acc, x) -> (
6       (acc.1) + ((((x.1).1) + ((polygon[((x.2) + 1) % (length(polygon) + 1)]).1)) * area(x.1, polygon[((x.2) + 1) % (length(polygon) + 1)])),
7       (acc.2) + ((((x.1).2) + ((polygon[((x.2) + 1) % (length(polygon) + 1)]).2)) * area(x.1, polygon[((x.2) + 1) % (length(polygon) + 1)])),
8       (acc.3) + area(x.1, polygon[((x.2) + 1) % (length(polygon) + 1)])), arrayZip(polygon, range(1, length(polygon) + 1)), (0.0, 0.0, 0.0)
9   )
10)
11
12CREATE FUNCTION centroid as polygon -> ((signed_area(polygon).1) / ((6 * (signed_area(polygon).3)) * 0.5), (signed_area(polygon).2) / ((6 * (signed_area(polygon).3)) * 0.5))
```
