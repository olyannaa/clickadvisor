```
1CREATE TABLE countries
2(
3  `name` String,
4  `coordinates` MultiPolygon
5)
6ENGINE = MergeTree
7ORDER BY name
8
9INSERT INTO countries
10SELECT name, coordinates
11FROM (
12SELECT JSONExtractString(JSONExtractString(json, 'properties'), 'ADMIN') as name,
13JSONExtractString(JSONExtractRaw(json, 'geometry'), 'type') as type,
14if(type == 'Polygon', [JSONExtract(JSONExtractRaw(JSONExtractRaw(json, 'geometry'), 'coordinates'), 'Polygon')], JSONExtract(JSONExtractRaw(JSONExtractRaw(json, 'geometry'), 'coordinates'), 'MultiPolygon')) as coordinates
15 	FROM (SELECT arrayJoin(JSONExtractArrayRaw(json, 'features')) as json
16       	FROM url('https://datasets-documentation.s3.eu-west-3.amazonaws.com/countries/countries.geojson', JSONAsString)))
```

Our country's polygons are represented as geoJSON and are available here. The above `INSERT SELECT` extracts these polygons from the JSON using JSONExtract\* functions, storing them in the `countries` table.

And yet again we have a video for this very topic covering the query and subsequent dictionary:

```
1CREATE DICTIONARY country_polygons
2(
3    `coordinates` MultiPolygon,
4    `name` String
5)
6PRIMARY KEY coordinates
7SOURCE(CLICKHOUSE(TABLE 'countries'))
8LIFETIME(MIN 0 MAX 0)
9LAYOUT(POLYGON(STORE_POLYGON_KEY_COLUMN 1))
```
Copy command
This dictionary is indexed by the coordinates of our polygon and allows us to retrieve the polygon associated with a specific latitude and longitude using the [`dictGet`](https://clickhouse.com/docs/en/sql-reference/functions/ext-dict-functions#dictGet) function. For example,

```
1SELECT dictGet(country_polygons, 'name', (-2.72647, 55.599621)) AS location
2
3┌─location───────┐
4│ United Kingdom │
5└────────────────┘
61 row in set. Elapsed: 0.012 sec.
```

Notice the speed of retrieval here. Aside from being useful in our later visualizations, this dictionary allows us to obtain quick insight into the internet speeds of different countries. For example, we can quickly determine that maybe the South Georgia islands are the best place to live for fast internet!
