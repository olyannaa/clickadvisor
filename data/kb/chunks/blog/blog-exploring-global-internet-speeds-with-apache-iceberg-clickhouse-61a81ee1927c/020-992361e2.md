1<!doctype html>
2<html>

12       async function render(tile) {
13           const url = `http://localhost:8123/?user=default&default_format=RowBinary`;
14           const response = await fetch(url, { method: 'POST', body: 'SELECT * FROM ookla_as_pixels' });
15           if (!response.ok) {
16               const text = await response.text();
17               let err = document.getElementById('error');
18               err.textContent = text;
19               err.style.display = 'block';
20               return;
21           }
22           buf = await response.arrayBuffer();
23           let ctx = tile.getContext('2d');
24           let image = ctx.createImageData(2048, 2048);
25           let arr = new Uint8ClampedArray(buf);
26
27           for (let i = 0; i < 2048 * 2048 * 4; ++i) {
28               image.data[i] = arr[i];
29           }
30           ctx.putImageData(image, 0, 0, 0, 0, 2048, 2048);
31           let err = document.getElementById('error');
32           err.style.display = 'none';
33       }
34       const canvas = document.getElementById("canvas");
35       render(canvas).then((err) => {
36           if (err) {
37               let err = document.getElementById('error');
38               err.textContent = text;
39           } else {
40               err.style.display = 'none'
41           }
42       })
43   </script>
44</body>
45</html>

The above exploits the ClickHouse’s [HTTP interface](https://clickhouse.com/docs/en/interfaces/http) and ability to return results in [RowBinary format](https://clickhouse.com/docs/en/integrations/data-formats/binary-native#exporting-to-rowbinary). The creation of a view has significantly simplified our SQL query to simply `SELECT * FROM ookla_as_pixels`. Our resulting image.

## Conclusion \#

This post has introduced the Iceberg data format and discussed the current state of support in ClickHouse, with examples of how to query and import the data. We have explored the Ookla internet speed dataset, distributed in Iceberg format, and used the opportunity to explore h3 indexes, polygon dictionaries, Mercator projections, color interpolations, and centroid computation using UDFs \- all with the aim of visualizing the data with just SQL.
