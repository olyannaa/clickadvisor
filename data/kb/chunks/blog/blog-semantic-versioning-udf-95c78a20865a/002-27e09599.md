5 ) ``` Copy command ## Versions as ints in strings \# Versions are most commonly stored as strings in databases. As many of you may know, sorting version strings using lexicographical order will not work as expected.

```
1SELECT *
2FROM
3(
4    SELECT ['1.0', '2.0', '3.0.0', '10.0'] AS versions
5)
6ARRAY JOIN versions
7ORDER BY versions DESC
8
9┌─versions─┐
10│ 3.0.0    │
11│ 2.0      │
12│ 10.0     │ << ???
13│ 1.0      │
14└──────────┘
```
Copy command
The basic idea is that we will use int arrays and sort those instead. If we rewrite our semantic versions as arrays of ints, sorting works as expected. It even works for versions with different lengths!

```
1SELECT *
2FROM
3(
4    SELECT [[1, 0], [2, 0], [3, 0, 0], [10, 0]] AS versions
5)
6ARRAY JOIN versions
7ORDER BY versions DESC
8
9┌─versions─┐
10│ [10,0]   │
11│ [3,0,0]  │
12│ [2,0]    │
13│ [1,0]    │
14└──────────┘
```
Copy command
Let’s write a lambda function to transform a version string into an array of ints.

```
1SELECT
2    version,
3    arrayMap(x -> toUInt32(x), splitByChar('.', version)) AS sem_ver_arr
4FROM
5(
6    SELECT ['1.0', '2.0', '3.0.0', '10.0'] AS version
7)
8ARRAY JOIN version
9ORDER BY sem_ver_arr DESC
10
11┌─version─┬─sem_ver_arr─┐
12│ 10.0    │ [10,0]      │
13│ 3.0.0   │ [3,0,0]     │
14│ 2.0     │ [2,0]       │
15│ 1.0     │ [1,0]       │
16└─────────┴─────────────┘
```
Copy command
Let’s break that down:

1. `splitByChar('.', version)` splits the version string into an array of strings on the period `.`, transforming `10.0` into `['10', '0']`.
2. `arrayMap(x -> toUInt32(x), arr)` converts each number string into an int32

We can save some typing by defining a UDF:

```
1CREATE FUNCTION sortableSemVer AS version -> 
2  arrayMap(x -> toUInt32(x), splitByChar('.', version));
```
Copy command
Let’s use it!

```
1SELECT
2    version,
3    sortableSemVer(version) AS sem_ver_arr
4FROM
5(
6    SELECT ['1.0', '2.0', '3.0.0', '10.0'] AS version
7)
8ARRAY JOIN version
9ORDER BY sem_ver_arr DESC
10
11┌─version─┬─sem_ver_arr─┐
12│ 10.0    │ [10,0]      │
13│ 3.0.0   │ [3,0,0]     │
14│ 2.0     │ [2,0]       │
15│ 1.0     │ [1,0]       │
16└─────────┴─────────────┘
```
Copy command
You can even exclude the sem\_ver\_arr column all together and only use the `sortableSemVer` in the `ORDER BY` clause.
