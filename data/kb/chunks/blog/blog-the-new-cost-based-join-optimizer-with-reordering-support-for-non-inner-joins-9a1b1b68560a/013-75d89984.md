## Using it \#

Our new DPsub with the conflict detector is the default Cost\-Based Optimizer (CBO) for joins starting with 26\.10 release:

```
1SET query_plan_optimize_join_order_algorithm = 'dpsub,greedy';  -- greedy is the fallback for large Joins
2SET query_plan_optimize_join_order_conflict_detector = 'c';     -- setting to'' turns it off
```
Copy command
If you want to compare with the previous behavior, you can switch it off per query. To get more details and look at the join order, kind and strictness of every join run with `EXPLAIN actions = 1`:

```
1EXPLAIN actions = 1
2SELECT ...
3SETTINGS query_plan_optimize_join_order_algorithm = 'greedy',
4         query_plan_optimize_join_order_conflict_detector = ''
```
