continue as usual, copying 8 bytes at once: `abcabcabcabcabcabca..... ^^^^^^^^ - src ^^^^^^^^ - dst` As we all know from experience, sometimes the best way to understand code is to rewrite it. Here's what we came up with:

```
1inline void copyOverlap8(UInt8 * op, const UInt8 *& match, const size_t offset)
2{
3    /// 4 % n.
4    /// Or if 4 % n is zero, we use n.
5    /// It gives an equivalent result, but is more CPU friendly for unknown reasons.
6    static constexpr int shift1[] = { 0, 1, 2, 1, 4, 4, 4, 4 };
7
8    /// 8 % n - 4 % n
9    static constexpr int shift2[] = { 0, 0, 0, 1, 0, -1, -2, -3 };
10
11    op[0] = match[0];
12    op[1] = match[1];
13    op[2] = match[2];
14    op[3] = match[3];
15
16    match += shift1[offset];
17    memcpy(op + 4, match, 4);
18    match += shift2[offset];
19}
```

As expected, this doesn't change the performance at all. I just really wanted to try optimization for copying 16 bytes at once.
