Consider the example we use for our [integration with dbt](https://clickhouse.com/docs/en/integrations/dbt#dbt). This consists of a small IMDB dataset with the following relational schema. This dataset originates from the [relational dataset repository](https://relational.fit.cvut.cz/dataset/IMDb).

![movies.png](/_next/image?url=%2Fuploads%2Fmovies_9bed1a31f2.png&w=2048&q=75)

Assuming you’ve created and populated these tables in ClickHouse, as described in [our documentation](https://clickhouse.com/docs/en/integrations/dbt#prepare-clickhouse), the following query can be used to compute a summary of each actor, ordered by the most movie appearances.

```
1SELECT
2	id,
3	any(actor_name) AS name,
4	uniqExact(movie_id) AS num_movies,
5	avg(rank) AS avg_rank,
6	uniqExact(genre) AS unique_genres,
7	uniqExact(director_name) AS uniq_directors,
8	max(created_at) AS updated_at
9FROM
10(
11	SELECT
12    	imdb.actors.id AS id,
13    	concat(imdb.actors.first_name, ' ', imdb.actors.last_name) AS actor_name,
14    	imdb.movies.id AS movie_id,
15    	imdb.movies.rank AS rank,
16    	genre,
17    	concat(imdb.directors.first_name, ' ', imdb.directors.last_name) AS director_name,
18    	created_at
19	FROM imdb.actors
20	INNER JOIN imdb.roles ON imdb.roles.actor_id = imdb.actors.id
21	LEFT JOIN imdb.movies ON imdb.movies.id = imdb.roles.movie_id
22	LEFT JOIN imdb.genres ON imdb.genres.movie_id = imdb.movies.id
23	LEFT JOIN imdb.movie_directors ON imdb.movie_directors.movie_id = imdb.movies.id
24	LEFT JOIN imdb.directors ON imdb.directors.id = imdb.movie_directors.director_id
25)
26GROUP BY id
27ORDER BY num_movies DESC
28LIMIT 5
```
