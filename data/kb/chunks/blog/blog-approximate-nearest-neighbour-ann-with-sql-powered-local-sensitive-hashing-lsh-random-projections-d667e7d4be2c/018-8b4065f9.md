300 dimensions, using the [randNormal](https://clickhouse.com/docs/en/sql-reference/functions/random-functions#randnormal) and [L2Norm](https://clickhouse.com/docs/en/sql-reference/functions/distance-functions#l2norm) functions in ClickHouse. There is some complexity here with the use of array functions \- we leave this as an exercise for the user to decompose in the interests of post\-brevity.

```
1INSERT INTO planes_simple SELECT projection / L2Norm(projection) AS projection
2FROM
3(
4    SELECT arrayJoin(arraySplit((x, y) -> y, groupArray(e), arrayMap(x -> ((x % 300) = 0), range(128 * 300)))) AS projection
5    FROM
6    (
7        SELECT CAST(randNormal(0, 1), 'Float32') AS e
8        FROM numbers(128 * 300)
9    )
10)
```

In this case, our planes consist of only a single point. This simplifies the query required to populate our table `glove_lsh_simple` with bit hashes. This simplification significantly improves insert time \- now only 43 seconds (down from 100 seconds).

```
1INSERT INTO glove_lsh_simple
2WITH
3    128 AS num_bits,
4    (
5        SELECT groupArray(projection) AS projections
6        FROM
7        (
8            SELECT *
9            FROM planes_simple
10            LIMIT num_bits
11        )
12    ) AS projections
13SELECT
14    word,
15    vector,
16    arraySum((projection, bit) -> bitShiftLeft(toUInt128(dotProduct(vector, projection) > 0), bit), projections, range(num_bits)) AS bits
17FROM glove
18SETTINGS max_block_size = 1000
19

```

Querying is also more straightforward and yields comparable results:

```
1WITH
2    'dog' AS search_term,
3    (
4        SELECT vector
5        FROM glove
6        WHERE word = search_term
7        LIMIT 1
8    ) AS target_vector,
9    128 AS num_bits,
10    (
11        SELECT groupArray(projection) AS projections
12        FROM
13        (
14            SELECT *
15            FROM planes_simple
16            LIMIT num_bits
17        )
18    ) AS projections,
19    (
20        SELECT arraySum((projection, bit) -> bitShiftLeft(toUInt128(dotProduct(target_vector, projection) > 0), bit), projections, range(num_bits))
21    ) AS target
22SELECT word
23FROM glove_lsh_simple
24WHERE word != search_term
25ORDER BY bitCount(bitXor(bits, target)) ASC
26LIMIT 5
```
