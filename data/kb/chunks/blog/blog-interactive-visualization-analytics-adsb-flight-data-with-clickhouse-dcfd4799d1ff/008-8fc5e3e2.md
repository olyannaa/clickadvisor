### Reports \#

If you select an area with the right mouse button or use a selection tool, it will generate a report from the database for the selection area. This is entirely straightforward. For example, here is a query for the top aircraft types:

```
1const sql_types = `
2	WITH mercator_x >= {left:UInt32} AND mercator_x < {right:UInt32}
3    	AND mercator_y >= {top:UInt32} AND mercator_y < {bottom:UInt32} AS in_tile
4	SELECT t, anyIf(desc, desc != '') AS desc, count() AS c
5	FROM {table:Identifier}
6	WHERE t != '' AND ,[object Object],
7	GROUP BY t
8	ORDER BY c DESC
9	LIMIT 100`;
```
Copy command
The report is calculated for flight numbers, aircraft types, registration (tail numbers), and owners. You can click on any item and it will apply a filter to the main SQL query. For example, click on A388 and it will show you a visualization for the Airbus 380\-800\.

As a bonus, if you move the cursor over an aircraft type, it will go to Wikipedia API and try to find a picture of this aircraft. It often finds something else on Wikipedia, though.

### Saved Queries \#

You can edit a query and then share a link. The query is converted to a 128\-bit hash and saved in the same ClickHouse database:

```
1async function saveQuery(text) {
2	const sql = `INSERT INTO saved_queries (text) FORMAT RawBLOB`;
3	const hosts = getHosts(null);
4	const url = host => `,[object Object],/?user=website_saved_queries&query=,[object Object],`;
5	const response = await Promise.all(hosts.map([object Object], => fetch(url(host), { method: 'POST', body: text })));
6}
7
8async function loadQuery(hash) {
9	const sql = `SELECT text FROM saved_queries WHERE hash = unhex({hash:String}) LIMIT 1`;
10	const hosts = getHosts(null);
11	const url = host => `,[object Object],/?user=website_saved_queries&default_format=JSON&param_hash=,[object Object],`;
12	const response = await Promise.race(hosts.map([object Object], => fetch(url(host), { method: 'POST', body: sql })));
13	const data = await response.json();
14	return data.data[0].text;
15}
```
Copy command
We use a different user `website_saved_queries` with different access control and quotas for these queries.
