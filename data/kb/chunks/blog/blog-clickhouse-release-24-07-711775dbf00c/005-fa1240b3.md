We use the [ClickBench](https://github.com/ClickHouse/ClickBench/tree/main?tab=readme-ov-file#clickbench-a-benchmark-for-analytical-databases) table, which contains 100 million anonymized page hits. First, we create the table by running the [provided DDL statement](https://github.com/ClickHouse/ClickBench/blob/main/clickhouse/create.sql). Next, we insert the data:

```
1INSERT INTO hits SELECT * FROM s3('s3://clickhouse-public-datasets/hits_compatible/hits.parquet');
```

After the data load, the table should contain \~100 million rows:

```
1SELECT count()
2FROM hits;
3
4   ┌──count()─┐
51. │ 99997497 │ -- 100.00 million
6   └──────────┘
```
Copy command
We run a JOIN query performing a self\-join. Note that this JOIN is using the hash join algorithm by [default](https://clickhouse.com/docs/en/operations/settings/settings#join_algorithm):

```
1SELECT count()
2FROM hits AS t1
3INNER JOIN hits AS t2 ON t1.ClientIP = t2.RemoteIP
4WHERE t1.ClientIP != 0;
5
6   ┌─count()─┐
71. │ 3395861 │ -- 3.40 million
8   └─────────┘
9
101 row in set. Elapsed: 5.112 sec. Processed 199.99 million rows, 799.98 MB (39.12 million rows/s., 156.49 MB/s.)
11Peak memory usage: 3.25 GiB.
```
Copy command
Now we run the same JOIN query with the parallel hash join algorithm:

```
1SELECT count()
2FROM hits AS t1
3INNER JOIN hits AS t2 ON t1.ClientIP = t2.RemoteIP
4WHERE t1.ClientIP != 0
5SETTINGS join_algorithm = 'parallel_hash';
6
7   ┌─count()─┐
81. │ 3395861 │ -- 3.40 million
9   └─────────┘
10
111 row in set. Elapsed: 0.517 sec. Processed 199.99 million rows, 799.98 MB (387.03 million rows/s., 1.55 GB/s.)
12Peak memory usage: 3.44 GiB.
```
Copy command
Note that this query runs 10 times faster on the same hardware.

When we run the query for the first time since the ClickHouse process got started, with the parallel hash join algorithm and enabled trace\-level logging, then we can observe log messages indicating that ClickHouse is collecting and caching hash table size statistics:

```

3INNER JOIN hits AS t2 ON t1.ClientIP = t2.RemoteIP
4WHERE t1.ClientIP != 0
```
