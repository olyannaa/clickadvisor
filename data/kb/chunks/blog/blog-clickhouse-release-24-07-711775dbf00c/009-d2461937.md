## Automatic named tuples \#

### Contributed by Amos Bird \#

A named tuple will be created if you specify aliases (using `AS`) for tuple elements. Let’s have a look at how this used to work in 24\.6:

```
1docker run --rm clickhouse/clickhouse-server:24.6 \
2  clickhouse-local \
3  --query \
4  "SELECT ('Hello' AS a, 123 AS b) AS x, 
5          toTypeName(x) AS type,
6          toJSONString(x) AS json
7   FORMAT Vertical"
```
Copy command

```
1Row 1:
2──────
3x:    ('Hello',123)
4type: Tuple(String, UInt8)
5json: ["Hello",123]
```
Copy command
And now, 24\.7:

```
1docker run --rm clickhouse/clickhouse-server:24.7 \
2  clickhouse-local \
3  --query \
4  "SELECT ('Hello' AS a, 123 AS b) AS x, 
5          toTypeName(x) AS type,
6          toJSONString(x) AS json
7   FORMAT Vertical"
```

```
