While the above gets us started, a more robust solution with error handling will likely be required. For this, we may wish to convert the above to Python. The Python script below adds basic error handling and retries with a backoff. The latter here is to specifically address the challenge of OpenAI rate limits \- see [Handling latency \& rate limits](/blog/clickhouse-open-ai-user-defined-functions-udfs#handling-latency--rate-limits) for more details.

Note the need for the [openai](https://github.com/openai/openai-python) and tenacity libraries for handling API requests and rate limiting.

```
1#!/usr/bin/python3
2import sys
3import openai
4from tenacity import (
5   retry,
6   stop_after_attempt,
7   wait_random_exponential,
8)
9
10openai.api_key = "<INSERT>"
11request_timeout = 3
12
13@retry(wait=wait_random_exponential(min=1, max=60), stop=stop_after_attempt(20))
14def completion_with_backoff(**kwargs):
15   return openai.ChatCompletion.create(**kwargs)
16
17def extract_sentiment(text):
18   if text == "":
19       return "NEUTRAL"
20   messages = [{"role": "system",
21                "content": "You are an AI language model trained to analyze and detect the sentiment of hackernews forum comments."},
22               {
23                   "role": "user",
24                   "content": f"Analyze the following hackernews comment and determine if the sentiment is: positive, negative or neutral. "
25                              f"Return only a single word, either POSITIVE, NEGATIVE or NEUTRAL: {text}"
26               }]
27   try:
28       response = completion_with_backoff(model="gpt-3.5-turbo", messages=messages, max_tokens=30, temperature=0, request_timeout=request_timeout)
29       return response.choices[0].message.content
30   except:
31       return "ERROR"
32
33for size in sys.stdin:
34   # collect a batch for performance
35   for row in range(0, int(size)):
36       print(extract_sentiment(sys.stdin.readline().strip()))
37   sys.stdout.flush()
```

*The chat\-based nature of the service makes evaluating multiple pieces of text for sentiment in a single request challenging. In order to keep these examples simple, we have made a request per row. A more optimized solution may batch requests and ask the endpoint to evaluate a set of text.*
