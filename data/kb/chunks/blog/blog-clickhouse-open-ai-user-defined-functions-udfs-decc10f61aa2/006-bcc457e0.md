REST API via a ClickHouse UDF. The simplicity of this request means even a straightforward bash script may be sufficient, as seen below (the below requires [jq](https://jqlang.github.io/jq/)). Further along, we demonstrate how to do this in Python directly.

```
1#!/bin/bash
2
3while read read_data; do
4  sentiment=$(curl -s https://api.openai.com/v1/chat/completions \
5  -H "Content-Type: application/json" \
6  -H "Authorization: Bearer <insert>" \
7  -d "{
8  \"model\": \"gpt-3.5-turbo\",
9  \"messages\": [
10    	{
11    	\"role\": \"system\",
12    	\"content\": \"You are an AI language model trained to analyze and detect the sentiment of forum comments.\"
13    	},
14    	{
15    	\"role\": \"user\",
16    	\"content\": \"Analyze the following Hacker News comment and determine if the sentiment is: positive, negative or neutral. Return only a single word, either POSITIVE, NEGATIVE or NEUTRAL: ${read_data}\"
17    	}
18  ],
19  \"temperature\": 0,
20  \"max_tokens\": 2,
21  \"temperature\": 0
22}" | jq -r '.choices[0].message.content')
23  printf "$sentiment";
24done
```

This script should be saved in the `user_scripts` directory of ClickHouse as `sentiment.sh` and made executable. The following entry should also be added to a file `openai_functions.xml` and saved to the ClickHouse configuration directory (typically `/etc/clickhouse-server/`).

```
1<functions>
2       <function>
3           <name>sentiment</name>
4           <type>executable</type>
5           <format>TabSeparated</format>
6           <return_type>String</return_type>
7           <argument>
8             <type>String</type>
9           </argument>
10           <command>sentiment.sh</command>
11           <command_read_timeout>10000</command_read_timeout>
12           <command_write_timeout>10000</command_write_timeout>
13           <max_command_execution_time>10000</max_command_execution_time>
14       </function>
15</functions>
```

This configuration makes the UDF available to ClickHouse. Other than modifying the timeouts here to allow for the latency of OpenAI requests, we provide a function name, `sentiment`, and specify the input and return types.
