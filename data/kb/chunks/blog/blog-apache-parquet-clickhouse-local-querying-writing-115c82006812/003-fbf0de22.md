In the example below, we assume our house price data has been exported to a single `house_prices.parquet` file and the use of ClickHouse Local to query unless stated otherwise.

### Reading schemas \#

Identifying the schema of any file can be achieved with the [DESCRIBE statement](https://clickhouse.com/docs/en/sql-reference/statements/describe-table) and [file table function](https://clickhouse.com/docs/en/sql-reference/functions/files#file):

```
1DESCRIBE TABLE file('house_prices.parquet')
2
3┌─name──────┬─type─────────────┬
4│ price 	│ Nullable(UInt32) │
5│ date  	│ Nullable(UInt16) │
6│ postcode1 │ Nullable(String) │
7│ postcode2 │ Nullable(String) │
8│ type  	│ Nullable(Int8)   │
9│ is_new	│ Nullable(UInt8)  │
10│ duration  │ Nullable(Int8)   │
11│ addr1 	│ Nullable(String) │
12│ addr2 	│ Nullable(String) │
13│ street	│ Nullable(String) │
14│ locality  │ Nullable(String) │
15│ town  	│ Nullable(String) │
16│ district  │ Nullable(String) │
17│ county	│ Nullable(String) |
18└───────────┴──────────────────┴
```
