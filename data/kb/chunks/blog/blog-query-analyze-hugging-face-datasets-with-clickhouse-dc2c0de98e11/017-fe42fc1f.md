While possible, this feels impractical for larger file listings. Below, we encapsulate this logic in a user defined function (UDF), to which the user only has to pass a dataset name. This relies on the predictable url format noted earlier for Hugging Face hosted Parquet files.

We start by producing a function which outputs a list of the files for a specific dataset name.

```
1CREATE OR REPLACE FUNCTION hugging_paths AS dataset -> (
2	SELECT arrayMap(x -> (x.1), JSONExtract(json, 'parquet_files', 'Array(Tuple(url String))'))
3	FROM url('https://datasets-server.huggingface.co/parquet?dataset=' || dataset, 'JSONAsString')
4)
5
6SELECT hugging_paths('blog_authorship_corpus') AS paths FORMAT Vertical
7
8Row 1:
9──────
10paths: ['https://huggingface.co/datasets/blog_authorship_corpus/resolve/refs%2Fconvert%2Fparquet/blog_authorship_corpus/train/0000.parquet','https://huggingface.co/datasets/blog_authorship_corpus/resolve/refs%2Fconvert%2Fparquet/blog_authorship_corpus/train/0001.parquet','https://huggingface.co/datasets/blog_authorship_corpus/resolve/refs%2Fconvert%2Fparquet/blog_authorship_corpus/validation/0000.parquet']
```

We can take this a little further using [string functions](https://clickhouse.com/docs/en/sql-reference/functions/string-search-functions) to create a UDF which calls the above function, outputting a pattern which captures all of the files for the dataset.

```
1CREATE OR REPLACE FUNCTION hf AS dataset -> (
2	WITH hugging_paths(dataset) as urls
3	SELECT multiIf(length(urls) = 0, '', length(urls) = 1, urls[1], 'https://huggingface.co/datasets/{' || arrayStringConcat(arrayMap(x -> replaceRegexpOne(replaceOne(x, 'https://huggingface.co/datasets/', ''), '\\.parquet$', ''), urls), ',') || '}.parquet')
4)
5
6SELECT hf('blog_authorship_corpus') AS pattern
7FORMAT Vertical
8
9Row 1:
10──────
11pattern: https://huggingface.co/datasets/{blog_authorship_corpus/resolve/refs%2Fconvert%2Fparquet/blog_authorship_corpus/train/0000,blog_authorship_corpus/resolve/refs%2Fconvert%2Fparquet/blog_authorship_corpus/train/0001,blog_authorship_corpus/resolve/refs%2Fconvert%2Fparquet/blog_authorship_corpus/validation/0000}.parquet
12
131 row in set. Elapsed: 1.633 sec.
```

With this simple function, we can query any Hugging Face dataset using just its name by simply invoking it as the parameter of the url function.
