ClickHouse Cloud integrates seamlessly into the Azure ecosystem. Customers can directly query data in Azure Blob Storage using the [azureBlobStorage table function](https://clickhouse.com/docs/en/sql-reference/table-functions/azureBlobStorage), or ingest data into ClickHouse Cloud via [ClickPipes](https://clickhouse.com/cloud/clickpipes) using a supported [source](https://clickhouse.com/docs/en/integrations/clickpipes/kafka#supported-data-sources) such as Azure Events Hubs. We also recently [launched a connector for Microsoft Power BI](https://clickhouse.com/blog/official-microsoft-power-bi-connector) which enables Azure customers to build visualizations and business\-level dashboards on top of data stored in ClickHouse.
