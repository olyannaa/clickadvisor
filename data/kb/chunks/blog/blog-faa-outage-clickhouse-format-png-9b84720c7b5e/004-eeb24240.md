64°W and from 22°N to 51°N is 1456 × 840 pixels. ## Step 1: aggregate on the server \# For every frame and every pixel, the server counts the positions and averages the altitude and the speed ([`pixels.sql`](https://github.com/ClickHouse/adsb.exposed/blob/faa-outage-2026-11-13/faa-outage-2026-11-13/pixels.sql)):

```
1WITH
2    toUInt32(4294967295 * ((-128 + 180) / 360)) AS x0,
3    toUInt32(4294967295 * ((-64 + 180) / 360)) AS x1,
4    toUInt32(4294967295 * (1 / 2 - log(tan((51 + 90) / 360 * pi())) / 2 / pi())) AS y0,
5    toUInt32(4294967295 * (1 / 2 - log(tan((22 + 90) / 360 * pi())) / 2 / pi())) AS y1,
6    toDateTime('2026-11-13 05:00:00', 'UTC') AS t0,
7    t0 + {h:UInt32} * 3600 AS hour_begin
8SELECT
9    toUInt16(intDiv(toUnixTimestamp(time) - toUnixTimestamp(t0), 300)) AS frame,
10    toUInt16(bitShiftRight(mercator_x - x0, 19)) AS px,
11    toUInt16(bitShiftRight(mercator_y - y0, 19)) AS py,
12    toUInt32(count()) AS c,
13    toFloat32(avg(altitude)) AS alt,
14    toFloat32(avg(ground_speed)) AS speed
15FROM planes_mercator
16WHERE time >= hour_begin AND time < hour_begin + 3600
17    AND mercator_x >= x0 AND mercator_x < x1
18    AND mercator_y >= y0 AND mercator_y < y1
19GROUP BY frame, px, py;
```

The day is the Eastern\-time day: midnight ET is 05:00 UTC. The query reads 42\.5 million positions and returns 9 million rows, one for each pixel that saw at least one aircraft in one of the 288 frames. That is about 31,000 lit pixels per frame on average, out of 1\.2 million.

The public endpoint of adsb.exposed limits a result to about a million rows. So the query takes the hour as a parameter, `{h:UInt32}`, and runs 24 times. `clickhouse-local` does this in one statement: the `url` table function expands `{0..23}` in a URL into 24 URLs, and here the glob is placed in the query parameter itself:

```
1URL="https://kvzqttvc2n.eu-west-1.aws.clickhouse-staging.com/?user=website&default_format=RowBinary&param_h={0..23}&query=$(python3 -c 'import sys, urllib.parse; print(urllib.parse.quote(sys.stdin.read(), safe=""))' < pixels.sql)"
2
3clickhouse local --query "
4    SELECT * FROM url('$URL', RowBinary, 'frame UInt16, px UInt16, py UInt16, c UInt32, alt Float32, speed Float32')
5    INTO OUTFILE 'pixels.native' TRUNCATE FORMAT Native
6    SETTINGS max_threads = 6"
```

Mind the `default_format=RowBinary`. The `url` function tells the client what format to parse, but not the server what format to send. The `website` user defaults to `TSV`, and parsing TSV as `RowBinary` fails with a confusing "Cannot read all data" error.
