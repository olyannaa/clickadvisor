The public `website` user of adsb.exposed is read\-only, so it cannot change the image size. But the default canvas is 1024 × 1024, and for a still image that is enough. This query fits two panels, one above the other, keeping the aspect ratio of the map. It runs on the server and returns the PNG in the HTTP response ([`before-after.sql`](https://github.com/ClickHouse/adsb.exposed/blob/faa-outage-2026-11-13/faa-outage-2026-11-13/before-after.sql)):

```
1WITH
2    toUInt32(4294967295 * ((-128 + 180) / 360)) AS x0,
3    toUInt32(4294967295 * ((-64 + 180) / 360)) AS x1,
4    toUInt32(4294967295 * (1 / 2 - log(tan((51 + 90) / 360 * pi())) / 2 / pi())) AS y0,
5    toUInt32(4294967295 * (1 / 2 - log(tan((22 + 90) / 360 * pi())) / 2 / pi())) AS y1,
6    -- Two panels of 1024 x 512, one above the other; keep the aspect ratio of the map.
7    512 / (y1 - y0) AS scale,
8    (1024 - (x1 - x0) * scale) / 2 AS left_margin,
9    time >= '2026-11-13 21:00:00' AS after,  -- 14:00 ET goes to the top panel, 20:00 ET to the bottom one
10    toInt32(left_margin + (mercator_x - x0) * scale) AS x,
11    toInt32((mercator_y - y0) * scale) + after * 512 AS y,
12    pow(least(count() / 20, 1), 1 / 5) AS transparency
13SELECT x, y,
14    toUInt8((1 + transparency) / 2 * (1 - least(avg(altitude), 50000) / 50000) * 255) AS r,
15    toUInt8(transparency * greatest(0, least(avg(altitude), 5000)) / 5000 * 255) AS g,
16    toUInt8(greatest(0, least(avg(ground_speed), 700)) / 700 * 255) AS b
17FROM planes_mercator
18WHERE ((time >= '2026-11-13 19:00:00' AND time < '2026-11-13 19:10:00')
19    OR (time >= '2026-11-14 01:00:00' AND time < '2026-11-14 01:10:00'))
20    AND mercator_x >= x0 AND mercator_x < x1
21    AND mercator_y >= y0 AND mercator_y < y1
22GROUP BY x, y
23FORMAT PNG;
```
