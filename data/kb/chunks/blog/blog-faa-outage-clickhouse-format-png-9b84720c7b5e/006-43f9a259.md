The clock is plain `formatDateTime` in the `America/New_York` and `UTC` time zones. The complete query ([`render.sql`](https://github.com/ClickHouse/adsb.exposed/blob/faa-outage-2026-11-13/faa-outage-2026-11-13/render.sql)):

```
1-- Renders the animation from the per-frame, per-pixel aggregates in `pixels.native`.
2-- Every row of the result is one pixel of one frame: (t, x, y, r, g, b).
3-- Rows are painted in the order they arrive, so the layers are sorted: background first, text last.
4
5WITH
6    1456 AS width,          -- map width in pixels
7    840 AS map_height,      -- the timeline goes below the map
8    288 AS frames,          -- one frame per 5 minutes
9
10    pixels AS
11    (
12        SELECT * FROM file('pixels.native')
13        WHERE px < width AND py < map_height AND frame < frames
14    ),
15
16    -- The faint trace of the whole day, repeated in every frame, so that the outline of the US
17    -- is still there when the sky is empty.
18    ghost AS
19    (
20        SELECT px, py, toUInt8(pow(log1p(total) / log1p(max(total) OVER ()), 1.5) * 55) AS v
21        FROM (SELECT px, py, sum(c) AS total FROM pixels GROUP BY px, py)
22        QUALIFY v >= 4
23    ),
24
25    -- The number of positions in every frame, for the timeline.
26    activity AS
27    (
28        SELECT frame, sum(c) / max(sum(c)) OVER () AS share
29        FROM pixels
30        GROUP BY frame
31    ),
32
33    -- A 3x5 bitmap font: five rows of three bits each.
34    map(
35        '0', '111101101101111', '1', '010110010010111', '2', '111001111100111', '3', '111001111001111',
36        '4', '101101111001001', '5', '111100111001111', '6', '111100111101111', '7', '111001001001001',
37        '8', '111101111101111', '9', '111101111001111', ':', '000010000010000', '.', '000000000000010',
38        '-', '000000111000000', ' ', '000000000000000',
39        'A', '010101111101101', 'B', '110101110101110', 'C', '111100100100111', 'D', '110101101101110',
40        'E', '111100110100111', 'F', '111100110100100', 'G', '111100101101111', 'I', '111010010010111',
41        'N', '110101101101101', 'O', '010101101101010', 'P', '111101111100100', 'R', '110101110101101',
42        'S', '111100111001111', 'T', '111010010010010', 'U', '101101101101111', 'V', '101101101101010',
43        'X', '101101010101101', 'Y', '101101010010010') AS font,
44
45    -- All the text, one row per string: the frame, the position of the top-left corner, the scale, the color.
46    texts AS
47    (
48        SELECT number AS frame, 20 AS x0, 16 AS y0, 4 AS scale,
49            'FAA OUTAGE - FRIDAY NOV 13 2026' AS text, 255 AS r, 255 AS g, 255 AS b
50        FROM numbers(frames)
51        UNION ALL
52        SELECT number, 20, 44, 4,
53            formatDateTime(toDateTime('2026-11-13 05:00:00', 'UTC') + number * 300, '%H:%i ET', 'America/New_York')
54            || '   ' || formatDateTime(toDateTime('2026-11-13 05:00:00', 'UTC') + number * 300, '%H:%i UTC', 'UTC'),
55            255, 210, 110
56        FROM numbers(frames)
57        UNION ALL
58        SELECT number, width - 20 - 12 * 8, map_height - 22, 2, 'ADSB.EXPOSED', 150, 150, 150
59        FROM numbers(frames)
60        UNION ALL
61        -- The hour labels under the timeline: 00:00, 03:00, ..., 24:00.
62        SELECT frame, toInt32(30 + (width - 60) * hour / 24 - 2.5 * 8), map_height + 72, 2,
63            leftPad(toString(hour), 2, '0') || ':00', 150, 150, 150
64        FROM (SELECT number * 3 AS hour FROM numbers(9)) ARRAY JOIN range(frames) AS frame
65    ),
66
67    text_pixels AS
68    (
69        SELECT frame,
70            x0 + ((char_num - 1) * 4 + bit % 3) * scale + dx AS x,  -- glyphs are 3 pixels wide, plus 1 of spacing
71            y0 + intDiv(bit, 3) * scale + dy AS y,
72            r, g, b
73        FROM texts
74        ARRAY JOIN arrayEnumerate(splitByString('', text)) AS char_num
75        ARRAY JOIN range(15) AS bit
76        ARRAY JOIN range(scale) AS dx
77        ARRAY JOIN range(scale) AS dy
78        WHERE substring(font[substring(text, char_num, 1)], bit + 1, 1) = '1'
79    ),
80
81    -- The timeline: a bar for every frame, highlighted for the current one.
82    timeline AS
83    (
84        SELECT
85            current AS frame,
86            toInt32(floor(30 + (width - 60) * bar / frames)) AS xa,
87            toInt32(floor(30 + (width - 60) * (bar + 1) / frames)) - 1 AS xb,
88            toInt32(48 * share) AS h,
89            multiIf(bar = current, (255, 200, 80), bar < current, (110, 110, 110), (55, 55, 55)) AS color
90        FROM (SELECT frame AS bar, share FROM activity) ARRAY JOIN range(frames) AS current
91    )
92
93SELECT t, toInt32(x) AS x, toInt32(y) AS y, toUInt8(round(r)) AS r, toUInt8(round(g)) AS g, toUInt8(round(b)) AS b
94FROM
95(
96    -- Layer 0: the ghost of the whole day.
97    SELECT 0 AS layer, frame AS t, px AS x, py AS y, v AS r, v AS g, v AS b
98    FROM ghost ARRAY JOIN range(frames) AS frame
99
100    UNION ALL
101
102    -- Layer 1: the aircraft, colored with the same formula as on adsb.exposed: red fades with the altitude,
103    -- green grows over the first 5000 feet (so the climbs and descents near airports are yellow), blue is the speed.
104    SELECT 1, frame, px, py,
105        (1 + transparency) / 2 * (1 - least(alt, 50000) / 50000) * 255,
106        transparency * greatest(0, least(alt, 5000)) / 5000 * 255,
107        greatest(0, least(speed, 700)) / 700 * 255
108    FROM (SELECT *, pow(least(c / 30, 1), 1 / 5) AS transparency FROM pixels)
109
110    UNION ALL
111
112    -- Layer 2: the timeline.
113    SELECT 2, frame, xa + dx, map_height + 66 - dy, color.1, color.2, color.3
114    FROM timeline
115    ARRAY JOIN range(xb - xa + 1) AS dx
116    ARRAY JOIN range(h + 1) AS dy
117
118    UNION ALL
119
120    -- Layer 3: the text.
121    SELECT 3, frame, x, y, r, g, b
122    FROM text_pixels
123)
124ORDER BY layer
125
126INTO OUTFILE 'faa-outage-2026-11-13.png' TRUNCATE
127FORMAT PNG
128SETTINGS
129    output_format_image_width = 1456,
130    output_format_image_height = 930,
131    -- One unit of `t` is 2/25 of a second: 80 ms per frame, the whole day in 23 seconds.
132    output_format_image_time_multiplier_seconds = 2,
133    output_format_image_time_divisor_seconds = 25;
```

The query produces about 130 million pixel rows: 117 million for the ghost, 9 million for the aircraft, and the rest for the timeline and the text. It writes all 288 frames in 31 seconds on a single machine.
