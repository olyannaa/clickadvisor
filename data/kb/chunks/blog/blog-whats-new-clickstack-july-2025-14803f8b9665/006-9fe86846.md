Now, it’s preserved as a full hierarchy. ![clickstack-map-rendering.png](/_next/image?url=%2Fuploads%2Fclickstack_map_rendering_ed897335ac.png&w=2048&q=75) *Classic Map\-based rendering of attributes* ![clickstack-json-rendering.png](/_next/image?url=%2Fuploads%2Fclickstack_json_rendering_39ebde57fc.png&w=2048&q=75) *Hierarchical rendering of attributes with JSON type* ### So how much better is the JSON type? \#

With HyperDX handling the heavy lifting of column auto\-completion and Lucene\-like query construction, the main benefit users will see is faster queries on the OTel columns which hold attributes such as `LogAttributes` due to reduced I/O. Additionally, unlike before when all values were converted to strings, the actual types of attributes are now preserved. This means if you send numeric or date attributes, their types remain intact, enabling direct and efficient comparisons.

To appreciate the benefit of this, let's consider the sample logging OTel dataset used by our ClickStack playground [play\-clickstack.clickhouse.com](https://play-clickstack.clickhouse.com/) (which itself uses the clickhouse instance for [sql.clickhouse.com](https://sql.clickhouse.com/)) with approximately 90m rows. The Map\-powered schema for this data:

```
1CREATE TABLE otel_v2.otel_logs
2(
3    `Timestamp` DateTime64(9) CODEC(Delta(8), ZSTD(1)),
4    `TimestampTime` DateTime DEFAULT toDateTime(Timestamp),
5    `TraceId` String CODEC(ZSTD(1)),
6    `SpanId` String CODEC(ZSTD(1)),
7    `TraceFlags` UInt8,
8    `SeverityText` LowCardinality(String) CODEC(ZSTD(1)),
9    `SeverityNumber` UInt8,
10    `ServiceName` LowCardinality(String) CODEC(ZSTD(1)),
11    `Body` String CODEC(ZSTD(1)),
12    `ResourceSchemaUrl` LowCardinality(String) CODEC(ZSTD(1)),
13    `ResourceAttributes` Map(LowCardinality(String), String) CODEC(ZSTD(1)),
14    `ScopeSchemaUrl` LowCardinality(String) CODEC(ZSTD(1)),
15    `ScopeName` String CODEC(ZSTD(1)),
16    `ScopeVersion` LowCardinality(String) CODEC(ZSTD(1)),
17    `ScopeAttributes` Map(LowCardinality(String), String) CODEC(ZSTD(1)),
18    `LogAttributes` Map(LowCardinality(String), String) CODEC(ZSTD(1)),
19    INDEX idx_trace_id TraceId TYPE bloom_filter(0.001) GRANULARITY 1,
20    INDEX idx_res_attr_key mapKeys(ResourceAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
21    INDEX idx_res_attr_value mapValues(ResourceAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
22    INDEX idx_scope_attr_key mapKeys(ScopeAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
23    INDEX idx_scope_attr_value mapValues(ScopeAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
24    INDEX idx_log_attr_key mapKeys(LogAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
25    INDEX idx_log_attr_value mapValues(LogAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
26    INDEX idx_body Body TYPE tokenbf_v1(32768, 3, 0) GRANULARITY 8
27)
28ENGINE = MergeTree
29PARTITION BY toDate(TimestampTime)
30PRIMARY KEY (ServiceName, TimestampTime)
31ORDER BY (ServiceName, TimestampTime, Timestamp)
```
