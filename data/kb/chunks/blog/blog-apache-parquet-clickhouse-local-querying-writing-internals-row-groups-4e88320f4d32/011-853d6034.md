we can use the new `ParquetMetadata` to identify the compression of each column \- below, we highlight the differences before and after sorting for the postcode1 column. Note how the uncompressed size of this column is dramatically reduced.

```
1INSERT INTO FUNCTION file('house_prices-ordered.parquet') SELECT *
2FROM uk_price_paid
3ORDER BY
4	postcode1 ASC,
5	postcode2 ASC,
6	addr1 ASC,
7	addr2 ASC
```
