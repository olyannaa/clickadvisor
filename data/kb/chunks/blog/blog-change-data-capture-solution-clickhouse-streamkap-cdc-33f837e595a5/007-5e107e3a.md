Nested arrays \& structs \# Below, we provide some examples of how complex structures are mapped to ClickHouse types automatically. For supporting Arrays containing structs, we need to alter Streamkap’s role in ClickHouse to set [flatten\_nested](https://clickhouse.com/docs/en/operations/settings/settings#flatten-nested) to 0:

```
1ALTER ROLE STREAMKAP_ROLE SETTINGS flatten_nested = 0;
```
Copy command
#### Nested struct field containing sub array \#

An input record is shown here in JSON format, where the key has only one field `id`:

```
1{
2	"id": 1,
3	"obj": {
4		"nb": 123,
5		"str": "abc",
6		"sub_arr": [
7			{
8				"sub_nb": 789,
9				"sub_str": "mnp"
10			}
11		]	
12	}
13}
```
Copy command
The resulting table. Not how the `obj` column has been mapped to an `Tuple(nb Int32, str String, sub_arr Array(Tuple(n Int32, s String)), sub_arr_str Array(String))` to handle the complex structure:

```
1SHOW CREATE TABLE chdb.streamkap_nested_struct_with_array
2
3CREATE TABLE chdb.streamkap_nested_struct_with_array
4(
5    `obj` Tuple(nb Int32, str String, sub_arr Array(Tuple(n Int32, s String)), sub_arr_str Array(String)) COMMENT 'obj',
6    `__deleted` Bool COMMENT '__deleted',
7    `_streamkap_ts_ms` Int64 COMMENT '_streamkap_ts_ms',
8    `_streamkap_partition` Int32 COMMENT '_streamkap_partition',
9    `id` Int32 COMMENT 'id',
10    `_streamkap_deleted` UInt8 MATERIALIZED if(__deleted = true, 1, 0)
11)
12ENGINE = ReplacingMergeTree(_streamkap_ts_ms, _streamkap_deleted)
13PARTITION BY _streamkap_partition
14PRIMARY KEY id
15ORDER BY id
16SETTINGS index_granularity = 8192
```
Copy command
Example data:

```
1SELECT *
2FROM chdb.streamkap_nested_struct_with_array
3LIMIT 1 format Vertical
4
5obj:                               (123,'abc',[(789,'mnp')],['efg']) 
6__deleted:                         false     
7_streamkap_ts_ms:                  1702519029407 
8_streamkap_partition:              0 
9id:                                1
```
Copy command
#### Nested array field containing sub struct \#

An input record is shown here as JSON format, where key has only one field `id`:

```
1{
2    "id": 1,
3    "arr": [
4        {
5            "nb": 123,
6            "str": "abc"
7        }
8    ]
9}
```
Copy command

```
1SHOW CREATE TABLE streamkap_nested_array_of_struct
2
3CREATE TABLE streamkap.streamkap_nested_array_of_struct
4(
5    `arr` Array(Tuple(nb Int32, str String)) COMMENT 'arr',
6    `__deleted` Bool COMMENT '__deleted',
7    `_streamkap_ts_ms` Int64 COMMENT '_streamkap_ts_ms',
8    `_streamkap_partition` Int32 COMMENT '_streamkap_partition',
9    `id` Int32 COMMENT 'id',
10    `_streamkap_deleted` UInt8 MATERIALIZED if(__deleted = true, 1, 0)
11)
12ENGINE = ReplacingMergeTree( _streamkap_ts_ms, _streamkap_deleted)
13PARTITION BY _streamkap_partition
14PRIMARY KEY id
15ORDER BY id
16SETTINGS index_granularity = 8192
```
Copy command
Example data:

```
1SELECT *
2FROM streamkap_nested_array_of_struct
3LIMIT 1 format Vertical
4
5arr:                            [(123,'abc')]
6__deleted:                      false
7_streamkap_ts_ms:               1702529856885
8_streamkap_partition:           0
9id:                             1
```
