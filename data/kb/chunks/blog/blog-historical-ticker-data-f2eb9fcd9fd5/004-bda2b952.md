It's computed by summing the notional value of every trade (`quote_qty`, which is price × qty) and dividing it by the total quantity traded. In the following query, we order symbols by notional volume traded (the amount of money that changed hands) rather than the number of units:

```
1WITH
2    sum(quote_qty) AS raw_volume_usdt,
3    sum(qty) AS raw_volume_base
4SELECT
5    symbol,
6    round(sum(quote_qty) / sum(qty), 2) AS vwap,
7    formatReadableQuantity(raw_volume_base) AS volume_base,
8    formatReadableQuantity(raw_volume_usdt) AS volume_usdt,
9    bar(raw_volume_usdt, 0, 13440000000, 20) AS chart
10FROM trades
11WHERE toDate(ts) = '2024-01-31'
12GROUP BY symbol
13ORDER BY raw_volume_usdt DESC;
```

Next, let's write a query for an OHLC (Open, High, Low, Close) candle for a given symbol on a given day. The following query computes this for Bitcoin for each hour on the 16th January 2024:

```
1SELECT toStartOfInterval(ts, INTERVAL 1 HOUR)::Time AS bucket,
2       argMin(price, ts) AS open,
3       max(price)        AS high,
4       min(price)        AS low,
5       argMax(price, ts) AS close,
6       round(sum(qty), 2) AS volume
7FROM trades
8WHERE symbol = 'BTCUSDT' AND toDate(ts) = '2024-01-16'
9GROUP BY bucket
10ORDER BY bucket;
```
