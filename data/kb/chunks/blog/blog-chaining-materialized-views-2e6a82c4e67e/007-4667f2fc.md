```
1CREATE MATERIALIZED VIEW byTenMinutes_mv TO byTenMinutes AS
2SELECT toStartOfMinute(dateTime) AS dateTime,
3       uniqMergeState(users) as users,
4       uniqMergeState(pages) as pages,
5       sumMergeState(updates) AS updates
6FROM byMinute
7GROUP BY dateTime;
```

If we query the `byTenMinutes` table it won’t have any data and once it does start populating, it will only pick up new data ingested into the `byMinute` table. But all is not lost, we can still write a query to backfill the old data:

```
1INSERT INTO byTenMinutes 
2SELECT toStartOfTenMinutes(dateTime),
3       uniqMergeState(users) AS users, uniqMergeState(pages) AS pages,
4       sumMergeState(updates) AS updates
5FROM byMinute
6GROUP BY dateTime;
```

We can then write the following query against `byTenMinutes` to return the data grouped by 10\-minute buckets:

```
1SELECT
2    dateTime AS dateTime,
3    uniqMerge(users) AS users,
4    uniqMerge(pages) AS pages,
5    sumMerge(updates) AS updates
6FROM byTenMinutes
7GROUP BY dateTime
8ORDER BY dateTime DESC
9LIMIT 10;
```
