And now we’re going to run a version of the above query, that finds the most popular PyPi projects, using the [remoteSecure](https://clickhouse.com/docs/en/sql-reference/table-functions/remote/#parameters) function.

```
1SELECT name, 
2
3       replaceOne(home_page, 'https://github.com/', '') AS repository,
4       sum(count) AS count
5FROM remoteSecure(
6  'clickpy-clickhouse.clickhouse.com',
7  'pypi.pypi_downloads',
8  'mark', {password:String}
9) AS pypi_downloads
10INNER JOIN
11(
12    SELECT name, argMax(home_page, version) AS home_page
13    FROM remoteSecure(
14      'clickpy-clickhouse.clickhouse.com', 
15      'pypi.projects',
16      'mark', {password:String} 
17    )
18    GROUP BY name
19) AS projects ON projects.name = pypi_downloads.project
20
21WHERE projects.home_page LIKE '%github%'
22
23GROUP BY ALL
24ORDER BY count DESC
25LIMIT 10;

As we’d expect, we get the same results as before. This query takes a bit longer to run because, although the JOIN is done on the ClickPy server, we are initializing a new connection to the ClickPy server each time we run the query. We can check that the join is done remotely by prefixing the query with `EXPLAIN PLAN`, which will return the following:

```

2│ ReadFromRemote (Read from remote replica) │
3└───────────────────────────────────────────┘
