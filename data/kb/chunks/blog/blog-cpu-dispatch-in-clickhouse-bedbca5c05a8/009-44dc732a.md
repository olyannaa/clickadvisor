efforts of Dmitriy Kovalkov who added the [CPU dispatching framework to ClickHouse](https://github.com/ClickHouse/ClickHouse/pull/10058). It served as a basis for the subsequent work described in this article. First, I want to show how we designed our dispatch framework in ClickHouse.

```
1enum class TargetArch : UInt32
2{
3    Default  = 0,         /// Without any additional compiler options.
4    SSE42    = (1 << 0),  /// SSE4.2
5    AVX      = (1 << 1),
6    AVX2     = (1 << 2),
7    AVX512F  = (1 << 3),
8    AVX512BW    = (1 << 4),
9    AVX512VBMI  = (1 << 5),
10    AVX512VBMI2 = (1 << 6),
11};
12
13/// Runtime detection.
14bool isArchSupported(TargetArch arch);
```

We define an enum `TargetArch` for the target architecture, and inside the `isArchSupported` function we use CPUID instruction set checks that we have already discussed.
Then we define a bunch of `BEGIN_INSTRUCTION_SET_SPECIFIC_CODE` sections that apply a target attribute to the whole code block.

For example, for clang:

```
1#   define BEGIN_AVX512F_SPECIFIC_CODE \
2_Pragma("clang attribute push(__attribute__((target(\"sse,sse2,sse3,ssse3,sse4,\
3    popcnt,avx,avx2, avx512f\"))), apply_to=function)")
4\
5#   define BEGIN_AVX2_SPECIFIC_CODE \
6_Pragma("clang attribute push(__attribute__((target(\"sse,sse2,sse3,ssse3,sse4,\
7    popcnt, avx,avx2\"))), apply_to=function)") \
8\
9#   define END_TARGET_SPECIFIC_CODE \
10_Pragma("clang attribute pop")
```

Then for each instruction set, we define a separate namespace `TargetSpecific::INSTRUCTION_SET`. Examples for AVX2 and AVX512:

```
1#define DECLARE_AVX2_SPECIFIC_CODE(...) \
2BEGIN_AVX2_SPECIFIC_CODE \
3namespace TargetSpecific::AVX2 { \
4    DUMMY_FUNCTION_DEFINITION \
5    using namespace DB::TargetSpecific::AVX2; \
6    __VA_ARGS__ \
7} \
8END_TARGET_SPECIFIC_CODE
9
10#define DECLARE_AVX512F_SPECIFIC_CODE(...) \
11BEGIN_AVX512F_SPECIFIC_CODE \
12namespace TargetSpecific::AVX512F { \
13    DUMMY_FUNCTION_DEFINITION \
14    using namespace DB::TargetSpecific::AVX512F; \
15    __VA_ARGS__ \
16} \
17END_TARGET_SPECIFIC_CODE
```
