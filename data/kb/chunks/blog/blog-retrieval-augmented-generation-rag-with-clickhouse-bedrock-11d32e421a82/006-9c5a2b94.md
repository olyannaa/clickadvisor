Given the above research, our RAG flow would invariably require us to be able to generate embeddings for text (e.g., to find similar questions). For this, we utilize a simple [Python UDF `embed.py`](https://github.com/ClickHouse/bedrock_rag/blob/main/embed.py), which can be invoked at query or insert time. This utilizes Amazon’s `titan-embed-text-v1` model available through Bedrock. The main code for `embed.py` is shown below, with full supporting files [here](https://github.com/ClickHouse/bedrock_rag):

```
1#!/usr/bin/python3
2import json
3import sys
4from bedrock import get_bedrock_client
5from tenacity import (
6   retry,
7   stop_after_attempt,
8   wait_random_exponential,
9)
10import logging
11logging.basicConfig(filename='embed.log', level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
12
13bedrock_runtime = get_bedrock_client(region="us-east-1", silent=True)
14
15accept = "application/json"
16contentType = "application/json"
17modelId = "amazon.titan-embed-text-v1"
18char_limit = 10000  # 1500 tokens effectively
19
20
21@retry(,[object Object],)
22def embeddings_with_backoff(**kwargs):
23   return bedrock_runtime.invoke_model(**kwargs)
24
25
26for size in sys.stdin:
27   # collect batch to process
28   for row in range(0, int(size)):
29       try:
30           text = sys.stdin.readline()
31           text = text[:char_limit]
32           body = json.dumps({"inputText": text})
33           response = embeddings_with_backoff(
34               body=body, modelId=modelId, accept=accept, contentType=contentType
35           )
36           response_body = json.loads(response.get("body").read())
37           embedding = response_body.get("embedding")
38           print(json.dumps(embedding))
39       except Exception as e:
40           logging.error(e)
41           print(json.dumps([]))
42   sys.stdout.flush()
```
