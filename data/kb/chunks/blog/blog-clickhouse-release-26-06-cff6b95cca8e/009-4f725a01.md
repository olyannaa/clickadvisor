## aiEmbed \#

### Contributed by George Larionov \#

26\.6 adds `aiEmbed` to the collection of experimental AI functions available in ClickHouse.

Let's have a look at how to use this locally using Ollama. We'll first configure a named collection that points to Ollama's embedding API endpoint, using the `qwen3-embedding` model:

```
1CREATE NAMED COLLECTION ollama_credentials AS
2    provider = 'openai',
3    endpoint = 'http://localhost:11434/v1/embeddings',
4    model = 'qwen3-embedding',
5    api_key = 'ollama';
```
Copy command
We can then configure AI functions and our credentials:

```
1SET allow_experimental_ai_functions = 1;
2SET ai_function_credentials = 'ollama_credentials';
```
Copy command
And we can then call the `aiEmbed` function:

```
1SELECT arraySlice(aiEmbed('Hello world'), 1, 10)
2FORMAT Vertical;
```
