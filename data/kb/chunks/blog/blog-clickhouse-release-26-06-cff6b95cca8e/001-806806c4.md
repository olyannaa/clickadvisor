# ClickHouse Release 26\.6

![neutral avatar 400804ae96](/_next/image?url=%2Fuploads%2Fneutral_avatar_400804ae96_5c370e757b.png&w=96&q=75)ClickHouseJul 3, 2026 · 14 minutes readAnother month goes by, which means it’s time for another release, and it's a special one with it being the [10\-year anniversary of ClickHouse being open\-source](https://clickhouse.com/blog/open-source-10).

The ClickHouse 26\.6 release is a **record\-breaking release**, containing 56 new features 🌞 79 performance optimizations 🏖️ 366 bug fixes 🍦

This release introduces hypothetical skip indexes, cascading refreshable materialized views, experimental support for continuous queries, and more!

## Hypothetical skip indexes \#

### Contributed by Yarik Briukhovetskyi \#

Starting from ClickHouse 26\.6, it’s possible to ask "what if I had this skip index?" without having to build it.

Hypothetical indexes live only in the current session and are invisible to other sessions and discarded when the session ends.
