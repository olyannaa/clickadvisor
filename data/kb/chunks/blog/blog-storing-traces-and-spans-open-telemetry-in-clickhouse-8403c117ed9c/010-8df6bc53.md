Span from the first trace to the first Span in the second trace to causally associate them. In the ClickHouse schema, we again rely on Array types and associating the positions of the columns `Links.TraceId`, `Links.SpanId`, and `Links.Attributes`.

Note that the collector is opinionated on the schema, including enforcing specific codecs. While these represent sensible choices for the general case, they prevent users from tuning the configuration to their needs via collector configuration. Users wishing to modify the codecs or the ORDER BY key, e.g., fit [user\-specific access patterns](https://clickhouse.com/docs/en/guides/improving-query-performance/sparse-primary-indexes/sparse-primary-indexes-intro), should pre\-create the table in advance.

```
1CREATE TABLE otel_traces
2(
3	`Timestamp` DateTime64(9) CODEC(Delta(8), ZSTD(1)),
4	`TraceId` String CODEC(ZSTD(1)),
5	`SpanId` String CODEC(ZSTD(1)),
6	`ParentSpanId` String CODEC(ZSTD(1)),
7	`TraceState` String CODEC(ZSTD(1)),
8	`SpanName` LowCardinality(String) CODEC(ZSTD(1)),
9	`SpanKind` LowCardinality(String) CODEC(ZSTD(1)),
10	`ServiceName` LowCardinality(String) CODEC(ZSTD(1)),
11	`ResourceAttributes` Map(LowCardinality(String), String) CODEC(ZSTD(1)),
12	`SpanAttributes` Map(LowCardinality(String), String) CODEC(ZSTD(1)),
13	`Duration` Int64 CODEC(ZSTD(1)),
14	`StatusCode` LowCardinality(String) CODEC(ZSTD(1)),
15	`StatusMessage` String CODEC(ZSTD(1)),
16	`Events.Timestamp` Array(DateTime64(9)) CODEC(ZSTD(1)),
17	`Events.Name` Array(LowCardinality(String)) CODEC(ZSTD(1)),
18	`Events.Attributes` Array(Map(LowCardinality(String), String)) CODEC(ZSTD(1)),
19	`Links.TraceId` Array(String) CODEC(ZSTD(1)),
20	`Links.SpanId` Array(String) CODEC(ZSTD(1)),
21	`Links.TraceState` Array(String) CODEC(ZSTD(1)),
22	`Links.Attributes` Array(Map(LowCardinality(String), String)) CODEC(ZSTD(1)),
23	INDEX idx_trace_id TraceId TYPE bloom_filter(0.001) GRANULARITY 1,
24	INDEX idx_res_attr_key mapKeys(ResourceAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
25	INDEX idx_res_attr_value mapValues(ResourceAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
26	INDEX idx_span_attr_key mapKeys(SpanAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
27	INDEX idx_span_attr_value mapValues(SpanAttributes) TYPE bloom_filter(0.01) GRANULARITY 1,
28	INDEX idx_duration Duration TYPE minmax GRANULARITY 1
29)
30ENGINE = MergeTree
31PARTITION BY toDate(Timestamp)
32ORDER BY (ServiceName, SpanName, toUnixTimestamp(Timestamp), TraceId)
33TTL toDateTime(Timestamp) + toIntervalDay(3)
34SETTINGS index_granularity = 8192, ttl_only_drop_parts = 1
```
