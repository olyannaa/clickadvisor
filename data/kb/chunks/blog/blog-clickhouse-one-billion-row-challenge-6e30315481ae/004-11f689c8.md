Copy command Computing the min, max, and mean of the temperature for each city requires a simple `GROUP BY` query. We utilize `-t` to ensure timing information is included. The challenge requires the output in a specific format:

```
1{Abha=-23.0/18.0/59.2, Abidjan=-16.2/26.0/67.3, Abéché=-10.0/29.4/69.0, Accra=-10.1/26.4/66.4, Addis Ababa=-23.7/16.0/67.0, Adelaide=-27.8/17.3/58.5, ...}
```
Copy command
To achieve this, we can use the [CustomSeparated](https://clickhouse.com/docs/en/sql-reference/formats#format-customseparated) output format and [format](https://clickhouse.com/docs/en/sql-reference/table-functions/format) function. This avoids the need to use any functions, such as groupArray, which collapses the rows to a single row. Below, we use the console mode of ClickHouse Local.

```
1SELECT format('{}={}/{}/{}', city, min(temperature), round(avg(temperature), 2), max(temperature))
2FROM file('measurements.txt', CSV, 'city String, temperature DECIMAL(8,1)')
3GROUP BY city
4ORDER BY city ASC
5FORMAT CustomSeparated
6SETTINGS 
7  format_custom_result_before_delimiter = '{', 
8  format_custom_result_after_delimiter = '}', 
9  format_custom_row_between_delimiter = ', ', 
10  format_custom_row_after_delimiter = '', 
11  format_csv_delimiter = ';'
12
13{Abha=-34.6/18/70.3, Abidjan=-22.8/25.99/73.5, Abéché=-25.3/29.4/80.1, Accra=-25.6/26.4/76.8, Addis Ababa=-38.3/16/67, Adelaide=-33.4/17.31/65.5, …}
```

## Improving performance \#

We can improve the above performance by observing that our CSV file doesn’t use value escaping. The CSV reader is therefore unnecessary \- we can simply read each line as a string and access the relevant substrings using the separator `;`.

```
1SELECT format('{}={}/{}/{}', city, min(temperature), round(avg(temperature), 2), max(temperature))
2FROM
3(
4	SELECT
5    	substringIndex(line, ';', 1) AS city,
6   	substringIndex(line, ';', -1)::Decimal(8, 1) AS temperature
7	FROM file('measurements.txt', LineAsString)
8)
9GROUP BY city
10ORDER BY city ASC FORMAT CustomSeparated
11SETTINGS 
12  format_custom_result_before_delimiter = '{', 
13  format_custom_result_after_delimiter = '}', 
14  format_custom_row_between_delimiter = ', ', 
15  format_custom_row_after_delimiter = '', 
16  format_csv_delimiter = ';'
17
18413 rows in set. Elapsed: 19.907 sec. Processed 1.00 billion rows, 13.79 GB (50.23 million rows/s., 692.86 MB/s.)
19Peak memory usage: 132.20 MiB.
```

This reduces our execution time to under 20s!
