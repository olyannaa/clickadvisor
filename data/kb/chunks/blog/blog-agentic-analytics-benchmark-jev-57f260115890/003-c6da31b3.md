For each failed run, the labeler hands the classifier the trajectory (question, reference and candidate SQL, results, final answer) and asks four questions in one call: which of sixteen failure sub\-modes fits, which system\-prompt rule would have prevented it, whether a schema hint up front would have helped, and whether the answer looks correct despite the fail verdict. Anything checkable from the SQL text, such as whether it filtered on the snapshot date, is decided in code and passed in as a fact, so the classifier only makes the judgment calls.

In code, the four questions are two choices and two yes/no probabilities, sent in one call with the trajectory as the state. This is the shape of the labeler as it ships in the repository, trimmed:

```
1from typesafe_sdk import TypeSafeClient, Choice, Noul
2
3questions = {
4    "sub_mode": Choice(
5        instructions="Given the question, the reference SQL and answer, and "
6                     "the candidate's SQL, results and final answer, pick the "
7                     "single most specific sub-mode for why it failed.",
8        criteria=SUB_MODES),    # 16 sub-modes, each with a one-line meaning
9    "prevented_by_rule": Choice(
10        instructions="Which judgment-call schema-prompt rule best explains "
11                     "the failure? Choose 'none' if no listed rule does.",
12        criteria=RULES),        # the rule set is a config file
13    "schema_hint_would_help": Noul(
14        instructions="Would a correct schema-use hint before the first "
15                     "query most likely have prevented this failure?"),
16    "correct_despite_fail": Noul(
17        instructions="Does the candidate's final answer actually look "
18                     "correct for the question, despite being scored a failure?"),
19}
20
21with TypeSafeClient() as client:
22    resp = client.system_one(state=trajectory, questions=questions)
23
24resp.choices["sub_mode"].choice            # e.g. "wrong_identifier"
25resp.nouls["correct_despite_fail"].noul    # a calibrated probability, 0 to 1
```
