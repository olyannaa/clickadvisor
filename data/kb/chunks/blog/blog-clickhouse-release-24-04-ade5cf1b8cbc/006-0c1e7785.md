Central Line map: ![ (5).png](/_next/image?url=%2Fuploads%2F5_406bc6cf00.png&w=2048&q=75) For this, we just need to modify our recursive CTE’s abort condition (stopping the CTE’s join iterations once a join partner with `Stratford` as the target station got added to the CTE table):

```
1WITH RECURSIVE Reachable_Stations AS
2(
3    SELECT Station_1, Station_2, Line, 1 AS stops
4    FROM Connections
5    WHERE Line = 'Central Line'
6      AND Station_1 = 'Oxford Circus'
7  UNION ALL
8    SELECT rs.Station_1 c.Station_2, c.Line, rs.stops + 1 AS stops
9    FROM Reachable_Stations AS rs, Connections AS c
10    WHERE rs.Line = c.Line
11      AND rs.Station_2 = c.Station_1
12      AND 'Stratford' NOT IN (SELECT Station_2 FROM Reachable_Stations)
13)
14SELECT max(stops) as stops
15FROM Reachable_Stations;
```

## QUALIFY \#

### Contributed by Maksim Kita \#

Another feature added in this release is the `QUALIFY` clause, which lets us filter on the value of window functions.

We will see how to use it with help from the [Window Functions \- Rankings](https://github.com/ClickHouse/examples/tree/main/LearnClickHouseWithMark/WindowFunctions-Ranking) example. The dataset contains hypothetical football players and their salaries. We can import it into ClickHouse like this:

```
1CREATE TABLE salaries ORDER BY team AS
2FROM url('https://raw.githubusercontent.com/ClickHouse/examples/main/LearnClickHouseWithMark/WindowFunctions-Aggregation/data/salaries.csv')
3SELECT * EXCEPT (weeklySalary), weeklySalary AS salary
4SETTINGS schema_inference_make_columns_nullable=0;
```

