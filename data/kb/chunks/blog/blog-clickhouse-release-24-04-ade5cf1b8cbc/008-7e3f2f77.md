This query works, but it’s pretty clunky. Now that we have the `QUALIFY` clause, we can filter the data without needing to introduce a CTE, as shown below:

```
1SELECT player, team, position AS pos, salary,
2       rank() OVER (PARTITION BY position ORDER BY salary DESC) AS posRank
3FROM salaries
4QUALIFY posRank <= 3
5ORDER BY salary DESC;
```
