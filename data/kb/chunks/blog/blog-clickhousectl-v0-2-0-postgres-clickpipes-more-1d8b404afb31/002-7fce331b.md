## ClickPipes \#

`clickhousectl` now creates and manages [ClickPipes](https://clickhouse.com/docs/integrations/clickpipes), ClickHouse Cloud's managed connectors for streaming and batch ingest.

Supported sources:

| Source | Mode | Subcommand |
| --- | --- | --- |
| S3 / GCP / Azure Blob | Batch | `clickpipe create object-storage` |
| Kafka / Redpanda / Confluent / MSK | Streaming | `clickpipe create kafka` |
| Amazon Kinesis | Streaming | `clickpipe create kinesis` |
| Postgres | CDC | `clickpipe create postgres` |
| MySQL | CDC | `clickpipe create mysql` |
| MongoDB | CDC | `clickpipe create mongodb` |
| BigQuery | Snapshot | `clickpipe create bigquery` |


Creating a Kafka pipe:

```
1clickhousectl cloud clickpipe create kafka <service-id> \
2  --name my-kafka-pipe \
3  --brokers 'broker:9092' --topics events \
4  --format JSONEachRow \
5  --kafka-type redpanda \
6  --auth SCRAM-SHA-256 --username user --password pass \
7  --ca-certificate ./ca.crt \
8  --database default --table events \
9  --column "event_id:Int64" --column "name:String"
```

Creating a Postgres CDC pipe:

```
1clickhousectl cloud clickpipe create postgres <service-id> \
2  --name my-pg-pipe \
3  --host db.example.com --pg-database mydb \
4  --username pguser --password pgpass \
5  --table-mapping "public.users:public_users" \
6  --table-mapping "public.orders:public_orders"
```
Copy command
Once a pipe is running, you can list, start, stop, scale, resync (for CDC pipes), and delete it:

```
1clickhousectl cloud clickpipe list <service-id>
2clickhousectl cloud clickpipe scale <service-id> <clickpipe-id> \
3  --replicas 2 --cpu-millicores 250 --memory-gb 1
4clickhousectl cloud clickpipe resync <service-id> <clickpipe-id>
```
