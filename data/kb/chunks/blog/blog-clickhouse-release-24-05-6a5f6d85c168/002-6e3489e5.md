Copy command
This looks like a good use case for the `Dynamic` type, so let’s create a table:

```
1CREATE TABLE sensor_readings (
2    sensor_id UInt32,
3    reading_time DateTime,
4    reading Dynamic
5) ENGINE = MergeTree()
6ORDER BY (sensor_id, reading_time);
```
Copy command
Now, we can run the following query to ingest the data:

```
1INSERT INTO sensor_readings
2SELECT * FROM 'sensors.json';
```
