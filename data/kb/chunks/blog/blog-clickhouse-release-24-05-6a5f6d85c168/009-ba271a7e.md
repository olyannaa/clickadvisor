As an example, we get an exception when we run this JOIN query with ClickHouse `24.4`:

```
1SELECT L.*, R.*
2FROM pypi_1b AS L INNER JOIN pypi_1b AS R 
3ON (L.country_code = R.country_code) AND (L.timestamp < R.timestamp)
4LIMIT 10
5FORMAT Null;
6
7Received exception from server (version 24.4.1): … INVALID_JOIN_ON_EXPRESSION
```
Copy command
Now, with version `24.5`, ClickHouse has experimental support for non\-equal conditions in the ON clause. Note that, for now, we need to enable the `allow_experimental_join_condition` setting for this:

```
1SELECT
2    L.*,
3    R.*
4FROM pypi_1b AS L
5INNER JOIN pypi_1b AS R ON 
6     L.country_code = R.country_code AND 
7     L.timestamp < R.timestamp
8LIMIT 10
9FORMAT Null
10SETTINGS
11    allow_experimental_join_condition = 1;
```
