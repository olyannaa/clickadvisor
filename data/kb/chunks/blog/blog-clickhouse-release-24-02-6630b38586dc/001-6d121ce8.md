## Automatic detection of file format \#

### Contributed by Pavel Kruglov \#

When processing files, ClickHouse will automatically detect the type of the file even if it doesn’t have a valid extension. For example, the following file `foo` contains data in JSON lines format:

```
1$ cat foo
2
3{"name": "John Doe", "age": 30, "city": "New York"}
4{"name": "Jane Doe", "age": 25, "city": "Los Angeles"}
5{"name": "Jim Beam", "age": 35, "city": "Chicago"}
6{"name": "Jill Hill", "age": 28, "city": "Houston"}
7{"name": "Jack Black", "age": 40, "city": "Philadelphia"}
```
