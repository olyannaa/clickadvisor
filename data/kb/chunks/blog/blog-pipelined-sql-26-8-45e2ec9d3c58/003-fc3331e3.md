## Adding columns with EXTEND \#

`EXTEND` adds calculated columns while retaining all the columns already in the pipeline.

```
1FROM uk_price_paid
2|> WHERE town = 'LONDON' AND date >= '2024-01-01'
3|> EXTEND round(price / 1000000, 2) AS price_millions
4|> SELECT date, district, price, price_millions
5|> ORDER BY price DESC
6|> LIMIT 3;
```
