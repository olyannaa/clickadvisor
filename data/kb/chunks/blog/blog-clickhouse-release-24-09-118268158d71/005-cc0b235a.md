[24\.8 release post](https://clickhouse.com/blog/clickhouse-release-24-08), we learned about the new `JSON` data type. This release sees more functions to operate on data in the `JSON` and `Dynamic` data types. Let’s see how to use them on this sample dataset: *data3\.json*

```
1{"id": 1, "name": "Mark"}
2{"id": "agerty", "name": "Dale"}
3{"id": "2021-01-04", "name": "Tom"}
4{"id": ["1", 2, "3"], "name": "Alexey", "location": "Netherlands"}
```
Copy command
We have the `[distinctJSONPaths](https://clickhouse.com/docs/en/sql-reference/aggregate-functions/reference/distinctjsonpaths)` function, which returns distinct JSON paths.

```
1SELECT distinctJSONPaths(json)
2FROM file('data3.json', JSONAsObject)
3FORMAT Vertical;
4
5Row 1:
6──────
7distinctJSONPaths(json): ['id','location','location.city','location.country','name']
```
Copy command
If you want to return the types as well, `distinctJSONPathsAndTypes` does that:

```
1SELECT distinctJSONPathsAndTypes(json)
2FROM file('data3.json', JSONAsObject)
3FORMAT Vertical;
4
5Row 1:
6──────
7distinctJSONPathsAndTypes(json): {'id':['Array(Nullable(String))','Int64','String'],'location':['String'],'location.city':['String'],'location.country':['String'],'name':['String']}
```
Copy command
Finally, we have `[distinctDynamicTypes](https://clickhouse.com/docs/en/sql-reference/aggregate-functions/reference/distinctdynamictypes)`, which returns distinct types for `Dynamic` columns.

```
1SELECT distinctDynamicTypes(json.id)
2FROM file('data3.json', JSONAsObject)
3FORMAT Vertical
4
5Row 1:
6──────
7distinctDynamicTypes(json.id): ['Array(Nullable(String))','Int64','String']
```

## \_headers column for URL engine \#

### Contributed by Flynn \#

## overlay function \#

If you need to replace a string fragment with another string, that just got easier with the `overlay` function. You provide the initial string, the replacement string, and then the index where you want the replacement string to start and how many characters should be replaced.

We can use this function to make sure everyone knows that [chDB](https://clickhouse.com/docs/en/chdb) is cool as well!

```
1SELECT overlay('ClickHouse is cool', 'and chDB are', 12, 2) AS res
2
3┌─res──────────────────────────┐
4│ ClickHouse and chDB are cool │
5└──────────────────────────────┘
```
