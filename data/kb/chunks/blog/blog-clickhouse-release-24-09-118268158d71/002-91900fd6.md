Let’s say we want to capture the count for each `uuid` every 10 seconds and store it in a new table called `events_snapshot`. The schema of `events_snapshot` would look like this:

```
1CREATE TABLE events_snapshot (
2    ts DateTime32,
3    uuid String,
4    count UInt64
5) 
6ENGINE = MergeTree 
7ORDER BY uuid;
```
Copy command
We could then create a refreshable materialized view to populate this table:

```
1SET allow_experimental_refreshable_materialized_view=1;
2
3CREATE MATERIALIZED VIEW events_snapshot_mv
4REFRESH EVERY 10 SECOND APPEND TO events_snapshot
5AS SELECT
6    now() AS ts,
7    uuid,
8    sum(count) AS count
9FROM events
10GROUP BY ALL;
```
