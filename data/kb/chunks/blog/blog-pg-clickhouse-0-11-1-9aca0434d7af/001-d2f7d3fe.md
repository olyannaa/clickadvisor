# pg\_clickhouse 0\.11\.1: Now with pgvector, UPDATE, DELETE pushdown

![image 512x512 1](/_next/image?url=%2Fuploads%2FImage_512x512_1_8bc569c360.png&w=96&q=75)[David Wheeler](/authors/david-wheeler)Nov 19, 2026 · 10 minutes readDon't let the minor version increment fool you: [pg\_clickhouse v0\.11\.1](https://github.com/ClickHouse/pg_clickhouse/releases/tag/v0.11.1),
released last week, delivers a slew of improvements and bug fixes, including
`UPDATE`, `DELETE`, `TRUNCATE`, and [pgvector](https://github.com/pgvector/pgvector) search pushdown.

## pgvector type mapping \#

Let's start with the latter: [pgvector](https://github.com/pgvector/pgvector) type mapping. Given this ClickHouse table:

```
1CALL clickhouse_perform('ch_server', $$
2    CREATE TABLE items (
3        id       Int32,
4        category String,
5        v        Array(Float32)
6    ) ENGINE = MergeTree ORDER BY (id);
7$$);
```
Copy command
[pg\_clickhouse v0\.11\.1](https://github.com/ClickHouse/pg_clickhouse/releases/tag/v0.11.1) lets us map the `v` column to the `vector` type:

```
1CREATE EXTENSION vector;
2CREATE FOREIGN TABLE items (
3    id       int NOT NULL,
4    category text NOT NULL,
5    v        vector(4) NOT NULL
6) SERVER ch_server;
```
Copy command
We use an explicit [CREATE FOREIGN TABLE](https://clickhouse.com/docs/products/managed-postgres/extensions/pg_clickhouse/reference#create-foreign-table) rather than [IMPORT FOREIGN SCHEMA](https://clickhouse.com/docs/products/managed-postgres/extensions/pg_clickhouse/reference#import-foreign-schema)
to map the ClickHouse `Array(Float32)` column to a PostgreSQL `vector` column.
It works for ClickHouse `Array(Float64)` columns, too. Now we can insert
`vector` array values:

```
1INSERT INTO items VALUES (0, 'a', '[0,0,0,0]');
2
3INSERT INTO items
4SELECT i, (ARRAY['a', 'b', 'c'])[i % 3 + 1],
5       format('[%s,%s,%s,%s]', sin(i), cos(i), sin(i * 2), cos(i * 3))::vector
6  FROM generate_series(1, 100) i;
```
Copy command
And of course select them:

```
1SELECT * FROM items ORDER BY id LIMIT 5;
```
