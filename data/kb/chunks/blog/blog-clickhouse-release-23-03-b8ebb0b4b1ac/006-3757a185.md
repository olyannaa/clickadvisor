```
1// enable tracing
2SET opentelemetry_trace_processors=1;
3SET opentelemetry_start_trace_probability=1;
4
5
6// run a query
7SELECT
8	toStartOfMonth(upload_date) AS month,
9	sum(view_count) AS `Youtube Views`,
10	bar(sum(has_subtitles) / count(), 0.55, 0.7, 100) AS `% Subtitles`
11FROM youtube
12WHERE (month >= '2020-08-01') AND (month <= '2021-08-01')
13GROUP BY month
14ORDER BY month ASC
15SETTINGS max_threads = 1

17Query id: 77931e25-b1a0-4eb1-82dc-786d95629f89
```

To ensure trace data is returned for the query id in the correct format, run the following from Grafana Explore. Ensure you set `Format=Trace` in the query editor.

```
1WITH '<query_id>' AS my_query_id
2SELECT
3	toString(trace_id) AS traceID,
4	toString(span_id) AS spanID,
5	if(toString(parent_span_id)='0', Null, parent_span_id) AS parentSpanID,
6	'ClickHouse' AS serviceName,
7	operation_name AS operationName,
8	start_time_us/1000 AS startTime,
9	finish_time_us/1000 AS finishTime,
10	(finish_time_us - start_time_us)/1000 AS duration,
11	arrayMap(key -> map('key', key, 'value', attribute[key]), mapKeys(attribute)) AS serviceTags
12FROM clusterAllReplicas('default', 'system', 'opentelemetry_span_log')
13WHERE trace_id IN (
14	SELECT trace_id
15	FROM clusterAllReplicas('default', 'system', 'opentelemetry_span_log')
16	WHERE (attribute['clickhouse.query_id']) = my_query_id
17)
18ORDER BY startTime ASC
```

Note we use the [clusterAllReplicas](https://clickhouse.com/docs/en/sql-reference/table-functions/cluster) function for ClickHouse Cloud only. Local users can use the `opentelemetry_span_log` table explicitly.
