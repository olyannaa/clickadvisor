**PRICING BASIS**

ClickHouse Cloud uses **$0\.3903 per compute unit (CU) per hour**. BigQuery uses the checked\-in [US list rates](https://cloud.google.com/bigquery/pricing): **$0\.025/GiB** for Storage Write API ingestion, **$0\.06/slot\-hour** for Enterprise Capacity, and **$6\.25/TiB** for On\-demand analysis. The [accepted summary](https://github.com/ClickHouse/CostBench/blob/main/full-path-realtime/quotes/bigquery/results/bq-full-t2-20260810_152224/charts/full_path_cost_performance_clickhouse_vs_bigquery_wide_summary.json) retains full\-precision inputs. Capacity and On\-demand are alternative modeled costs for the same jobs.

**① COMPLETE PREPARATION COST**

This covers the complete streaming\-ingestion meter, automatic reclustering at no separate charge, and the collected MV\-refresh usage.

**CLICKHOUSE CLOUD**

2 CUs × 36\.75 hours × $0\.3903/CU\-hour \= **$28\.68705**, including both HA ingest nodes.

**BIGQUERY INGESTION**

The [Write API meter](https://github.com/ClickHouse/CostBench/blob/main/full-path-realtime/quotes/bigquery/costs/out/bq-full-t2-20260810_152224/ingest.json) records **9,642\.7384687 GiB × $0\.025/GiB \= $241\.06846172**, using successful input bytes. Client\-acknowledged Arrow bytes and provider\-metered input bytes are distinct measures.

**BIGQUERY CLUSTERING**

Automatic reclustering is included without a separate charge. No paid manual reorganization job is added.

**BIGQUERY MV REFRESH**

The [362\-job export](https://github.com/ClickHouse/CostBench/blob/main/full-path-realtime/quotes/bigquery/costs/out/bq-full-t2-20260810_152224/mv_refresh.json) contains **121,166\.568 slot\-seconds**, priced at $0\.06/slot\-hour for **$2\.0194428**, or **4,137,783,656,448 billed bytes**, priced at $6\.25/TiB for **$23\.52057695**. Preparation totals are **$243\.08790452 Capacity** and **$264\.58903867 On\-demand**.

**② NORMALIZED QUERY COST**

BigQuery prices the same accepted query jobs by consumed slot\-seconds or billed bytes. ClickHouse prices recorded duration at its read\-side rate.

**CLICKHOUSE CLOUD**

8 CUs × $0\.3903/CU\-hour × (10\.324s aggregate \+ 47\.962s drill\-down) ÷ 3,600 ≈ **$0\.05055**, using the rounded cost\-summary inputs.

**BIGQUERY CAPACITY**

Aggregate jobs cost **$4\.29558297** and drill\-down jobs **$0\.45264198**, totaling **$4\.74822495**. The combined **79\.1370825 slot\-hours × $0\.06/slot\-hour** allocation uses recorded job slot consumption.

**BIGQUERY ON\-DEMAND**

Aggregate jobs cost **$20\.94800472** and drill\-down jobs **$3\.85683775**, totaling **$24\.80484247**. The combined billed volume is **3\.9687748 TiB × $6\.25/TiB**. This is an alternative to Capacity pricing, not an added component.
