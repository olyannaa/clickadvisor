This is best achieved in ClickHouse using the [Join table engine](https://clickhouse.com/docs/en/engines/table-engines/special/join/) and [joinGet](https://clickhouse.com/docs/en/sql-reference/functions/other-functions/#joinget) function. Suppose we have two tables \- one with all pageviews and the other with all logins tracked:

```
1CREATE TABLE pageviews
2(
3    `user_id` UInt64,
4    `time` DateTime,
5    `session_id` UInt64
6)
7ENGINE = MergeTree
8ORDER BY time;
9
10CREATE TABLE logins
11(
12    `user_id` UInt64,
13    `time` DateTime
14)
15ENGINE = MergeTree
16ORDER BY time;
```
Copy command
The difference between the tables is that the `logins` table only stores a single event per session. Suppose at some point in time, we decided to add the `session_id` column to the `logins` table:

```
1ALTER TABLE logins
2    ADD COLUMN `session_id` UInt64
```
Copy command
We now need to update the `logins.session_id` column with corresponding values from the `pageviews` table using a JOIN on `user_id` and `time`:

```
1SELECT *
2FROM logins AS l
3JOIN pageviews AS p ON (p.user_id = l.user_id) AND (p.time = l.time)
4
5┌─user_id─┬────────────────time─┬─p.user_id─┬──────────────p.time─┬─session_id─┐
6│       2 │ 2023-01-09 12:23:16 │         2 │ 2023-01-09 12:23:16 │ 2752888102 │
7│       1 │ 2023-01-09 13:23:16 │         1 │ 2023-01-09 13:23:16 │ 4135462640 │
8└─────────┴─────────────────────┴───────────┴─────────────────────┴────────────┘
```
Copy command
First, we need to create and populate a special [`Join`](https://clickhouse.com/docs/en/engines/table-engines/special/join/) table:

```
1CREATE TABLE pageviews_join
2ENGINE = Join(ANY, LEFT, user_id, time) AS
3SELECT *
4FROM pageviews
```
Copy command
This table will allow us to use the `joinGet` function to fetch values based on JOIN while executing an update query:

```
1ALTER TABLE logins
2    UPDATE session_id = joinGet('pageviews_join', 'session_id', user_id, time) WHERE session_id = 0
```
Copy command
And we can see, the `logins` table was updated accordingly with the JOIN:

```
1SELECT * FROM logins
2
3┌─user_id─┬────────────────time─┬─session_id─┐
4│       2 │ 2023-01-09 12:23:16 │ 2752888102 │
5│       1 │ 2023-01-09 13:23:16 │ 4135462640 │
6└─────────┴─────────────────────┴────────────┘
```
Copy command
Because we have altered the `logins` table by adding the `session_id` column, we can DROP the `pageviews_join` table once the changes are done (check the `system.mutations` table to be sure before dropping):

```
1DROP TABLE pageviews_join
```
Copy command
The same approach can be used to delete data with lightweight or mutation based deletes.
