### Choosing K \#

So far, we’ve assumed K has been identified. There are several techniques for determining the optimal value of K, the simplest of which is to compute the aggregate squared distance (SSE) between each point and its respective cluster for each value of K. This gives us a cost metric that we aim to minimize. The method `compute_d2_error` computes this using the following SQL query (assuming a value of 5 for K):

```
1WITH 5 as k_val,
2(
3       SELECT max(iteration)
4       FROM centroids WHERE k={k}
5) AS c_iteration,
6(
7   SELECT groupArray((centroid, position))
8   FROM
9   (
10       SELECT
11           centroid,
12           avgForEachMerge(vector) AS position
13       FROM centroids
14       WHERE iteration = c_iteration AND k=k_val
15       GROUP BY centroid
16   )
17) AS c_centroids
18SELECT
19   sum(pow((arraySort(c -> (c.2), arrayMap(x -> (x.1, L2Distance(x.2, vector)), c_centroids))[1]).2, 2)) AS distance
20FROM points
```
